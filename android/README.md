# تطبيقا الأندرويد — Kotlin + Jetpack Compose

**المرحلة 4 في خارطة الطريق** — يُبنيان بعد اكتمال الخادم وواجهات الويب (استراتيجية API-First).

```
android/
├── core/       # وحدة مشتركة: الشبكة، الثيم المركزي (من BRAND.md)، النماذج
├── customer/   # تطبيق الزبون
└── driver/     # تطبيق السائق (ورديات، GPS خلفي، الصندوق)
```

- أصليان 100% — لا WebView ولا تغليف (قرار مثبّت — PLAN.md §11).
- الثيم والنصوص مركزيان وفق GROUND-RULES (§1.1, §1.2).
