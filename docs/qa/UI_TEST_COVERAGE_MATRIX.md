## لم يُؤتمت بعد — بترتيب الخطر

| الشاشة | العنصر | لماذا لم يُؤتمت | يحتاج |
|---|---|---|---|
| **الدفع** | «أرسل الطلب» كاملاً | يحتاج خادماً + حساباً + عنواناً | E2E harness |
| **السلّة** | الشاشة نفسها | تعتمد `CartViewModel` + شبكة | ViewModel tests + خادم مزيّف |
| **التسوّق** | البحث · الأقسام · الأصناف | تعتمد شبكة | خادم مزيّف على المنفذ |
| **العنوان** | الخريطة | MapLibre على جهاز | Instrumentation + إذن موقع |
| **الطلبات** | شريط المراحل | يحتاج طلباً بحالات | Order lifecycle harness |
| **الحساب** | التعديل · الحذف | يحتاج حساباً | E2E |
| **قرص الحديث** | ظهوره وفتحه | يحتاج طلباً بسائق | E2E |
| **الافتتاح** | ظهوره مرّة | يحتاج عمليّة جديدة لكلّ حالة | Instrumentation |

**والفجوة الحقيقيّة واحدة: خادم اختبار للتطبيق.**
كلّ شاشة تجلب بيانات لا تُختبر بلا ذلك. **وهذا أوّل ما يُبنى بعد هذه الدفعة.**

## مزلقان في البيئة — موثّقان لأنّهما أوقفا التشغيل فعلاً

**١ · الشاشة تُقفل فيموت النشاط المضيف.** يسقط الاختبار بـ
`Activity has been destroyed already` — **وهو عطب بيئة يُقرأ عطب واجهة.**
الحلّ في البوّابة: `adb shell svc power stayon usb` قبل التشغيل.

**٢ · الجهاز يصير `offline`** إذا انقطعت الوصلة. المرحلة **غير حاجبة**
عمداً: **غياب جهاز ليس عطباً في التطبيق.** ومن أراد حجبها فليجعلها
`blocking=True` على مزرعة أجهزة.
