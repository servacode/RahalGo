## الأمر الواحد

```bash
python scripts/release-gate.py            # كلّ شيء
python scripts/release-gate.py --smoke    # السريعة، بعد كلّ تعديل
```

يطبع في آخره **«الإصدارُ مسموح»** أو **«الإصدارُ محجوب»** ويكتب
`docs/qa/last-run.json` للقراءة الآليّة.

## لماذا هذا الـStack وليس غيره

**اختير ما يناسب المشروع لا ما هو مشهور** — وهو شرط المالك.

| القرار | السبب المقيس |
|---|---|
| **Go `testing` للـAPI** | المحرّك Go فيه **٣٤٥ دالّة اختبارٍ** تعمل. إدخال لغةٍ ثانية للاختبار يعني بيئتين وCIين. |
| **`httptest` + الموجّه الكامل** | اختبارات المستودع القائمة تبني `Server{}` حقلاً حقلاً **فتتخطّى الوسائط كلَّها** — وهناك وقع BUG-002 بعينه. |
| **قاعدة حقيقيّة لا محاكاة** | المنطق الماليّ في SQL (قيود `CHECK` ومعاملات ذرّيّة). محاكاته تختبر المحاكاة. وهو مبدأ CI القائم أصلاً. |
| **`miniredis`** | Redis في الذاكرة — **لا خادم خارجيّ في CI**، ولا حدُّ إرسالٍ يتسرّب بين اختبارين. |
| **بايثون للبوّابة** | العربيّة لا تمرّ في سطر أوامر هذا الجهاز، و`Set-Content` تُفسد أيّ ملفّ فيه عربيّة. |

## الطبقة المبنيّة: `backend/internal/qa/`

**الغرض:** إثبات أنّ الخادم يفرض التخويل ويحسب المال بنفسه ولا يُنشئ طلباً مرّتين.

**الأداة:** Go `testing` + `net/http/httptest` + Postgres حقيقيّة + `miniredis`.

**كيف تُشغَّل:**
```bash
cd backend
TEST_DATABASE_URL=postgres://rahalgo:rahalgo_dev@localhost:5434/rahalgo_test?sslmode=disable \
  go test -count=1 -v ./internal/qa/
```

**ما تغطّيه:** نداءات HTTP حقيقيّة عبر **الموجّه نفسه الذي يعمل في الإنتاج** —
بكلّ وسائطه: التخويل، منع التكرار، ترجمة الأخطاء، إعلان التغييرات.

**ما لا تغطّيه:** لا تلمس أندرويد إطلاقاً. لا شاشة ولا ViewModel ولا شبكة عميل.
ولا تختبر رمز واتساب (المصنع يتجاوزه عمداً — انظر أدناه).

### العائلات والمعرّفات

| البادئة | ما تقيس | تحجب الإصدار؟ |
|---|---|---|
| `AUTH-*` | التوكن والدور | **نعم** |
| `SEC-IDOR-*` | مورد حسابٍ لا يقرؤه غيره | **نعم** |
| `FIN-*` | الأرقام تُحسب في الخادم | **نعم** |
| `VAL-*` | المُدخَل الفاسد يُردّ ٤٠٠ لا ٥٠٠ | **نعم** |
| `IDEM-*` | نداءان بمفتاحٍ واحد = فعلٌ واحد | **نعم** |
| `OBS-*` | ملاحظة مسجَّلة حمراء عمداً | **لا** |

## البيانات: تُصنع ولا تُلتقط

**اختبار يقرأ «أوّل صنف في السوق» يسقط يوم يُحذف.** فكلّ اختبار يصنع ما
يحتاجه بمعرّفات فريدة (`uniq()`) وينظّف بـ`t.Cleanup`.

المصانع المتاحة: `Customer()` · `NewUser(role)` · `NewItem(price)` (يصنع
تصنيفاً ومتجراً وقسماً معه) · `Setting(k,v)` (يُعيد القديم بعده) ·
`ExpiredToken()` · `signWith(secret,…)` للتزوير.

**ولا تمسّ الإنتاج:** `testdb.Pool` **يرفض قاعدةً لا ينتهي اسمها بـ`_test`**
ويتخطّى بهدوء إن لم تُضبط `TEST_DATABASE_URL`.

### ولماذا يتجاوز المصنع رمز واتساب

**من أراد اختبار IDOR لا يريد أن يسقط اختباره لأنّ حدّ الإرسال بلغ حدّه.**
فالحساب يُنشأ في القاعدة مباشرة وتوكنه يُصدَر بـ`TokenIssuer` نفسه.
**ودورة الرمز نفسها تحتاج حزمتها** (`OTP-*`) — ولم تُبنَ.

## ما كشفته المنظومة عن نفسها في أوّل تشغيل

**قاعدة عمل لم تكن مكتوبة في أيّ وثيقة:** الطلب يُردّ `whatsapp_required`
ما لم يكن الحساب موثّقاً على واتساب. اكتشفها الهيكل حين سقط، ولم تكن في
`TRUTH.md` ولا في تقرير التدقيق.

**وهذا بعينه ما تشتريه المنظومة:** قاعدة لا يعرفها إلّا من قاد النظام.

## القاعدة الدائمة

> **عطب يُكتشف ← اختبار أحمر يُكتب ← يُصلَح العطب ← يصير أخضر ← يبقى إلى الأبد.**

`OBS-001` أوّل مثال حيّ: مسجّل أحمر الآن، ولا يحجب، ويُصلَح بإذن منفصل.
