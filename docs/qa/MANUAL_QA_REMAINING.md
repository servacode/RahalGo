# ما يبقى بشريّاً — وسببه

> القاعدة: **إن أمكن أتمتته فيُؤتمت.** ولا يدخل هذا الملفّ زرٌّ عاديّ.
> يُختصر كلّما بُنيت طبقة.

---

## يبقى بشريّاً بسبب تقنيّ حقيقيّ

| ما هو | لماذا لا يُؤتمت |
|---|---|
| **رمز واتساب** | يصل إلى واتساب شخصيّ. قراءته آليّاً = فتح تطبيق المالك الشخصيّ — **خطّ لا يُعبر.** والمصنع يتجاوز الرمز في اختبارات API؛ ودورة الرمز نفسها تحتاج مزوّداً تجريبيّاً. |
| **جودة GPS الحقيقيّة** | الدقّة داخل بناء، التذبذب، البطء. المحاكاة تعطي نقطة مثاليّة لا تشبه الواقع. |
| **الإحساس البصريّ** | «هل يبدو مزدحماً؟» «هل الحركة مريحة؟» — لا يقيسه رقم. |
| **الكاميرا الحقيقيّة** | التقاط صورة من عدسة الجهاز. |
| **تكاملات خارجيّة حيّة** | بوت واتساب، مزوّد SMS. |

---

## يبقى بشريّاً **مؤقّتاً** — حتّى تُبنى طبقته

| ما هو | الطبقة التي تُلغيه | الحال |
|---|---|---|
| كلّ ضغطة في الشاشات | واجهة أندرويد آليّة (Compose UI Test) | لم تُبنَ |
| السلّة والمجاميع في الشاشة | ViewModel Tests | لم تُبنَ |
| دورة الطلب مع سائق | E2E + Order Lifecycle Harness | لم تُبنَ |
| موت العمليّة والدوران | Instrumentation Tests | لم تُبنَ |
| أسماء الحقول بين التطبيق والخادم | Contract Tests | لم تُبنَ |
| القصّ والخطّ الكبير وRTL | لقطات + اختبارات RTL | لم تُبنَ |

**وهذه ليست أعذاراً — هي قائمة عمل.** كلّ سطر منها يُشطب حين تُبنى طبقته.
