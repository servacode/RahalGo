# أرشيفٌ — **لا يُبنى عليه**

> هذه وثائقُ سبقت `TRUTH.md`. **تُقرأ لتاريخها لا لقراراتها**، وأيُّ تعارضٍ
> بينها وبين `../TRUTH.md` **يُحسم لصالح تلك.**

## لماذا أُرشِّفت

كان كلٌّ منها يقول إنّه المرجع: `PLAN.md` «المرجعُ الثابت»، و`ROADMAP.md`
«التسلسلُ المعتمد»، و`POLICY-OPERATIONS.md` سياسةُ التشغيل.

**وقرارٌ يُكتب في واحدةٍ لا يُنقل إلى الثلاث** — فيُبنى بندٌ على قرارٍ نُسخ منه
غيرُه. **وأربعةُ مراجعَ يعني لا مرجع.**

| الملف | ما كان |
|---|---|
| `PLAN.md` | الخطّةُ الأولى — قراراتٌ كثيرٌ منها تجاوزَه الواقع |
| `ROADMAP.md` | مراحلُ التنفيذ ومعاييرُ قبولها |
| `PROGRESS.md` | سجلُّ ما أُنجز مرحلةً مرحلة |
| `REVIEW_NOTES.md` | ملاحظاتُ مراجعةٍ قديمة |
| `CYCLE-PLATFORM-MANAGED.md` | دورةُ وضعٍ واحد — **وقد صارت في `TRUTH.md` للوضعين** |
