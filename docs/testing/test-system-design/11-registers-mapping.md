# ٤٥ · انحدارُ العيوب — **٢٢ من ٢٢**

## القاعدة

```
DEFECT FIXED + REGRESSION TEST PASS + IMPACTED TESTS PASS  ⇒  DEFECT CLOSED
```

**ولا يُغلَق عيبٌ بإصلاح الشيفرة وحدَها** — **فالإصلاحُ بلا حارسٍ يعود.**

# ٤٧ · فجواتُ العقد — **٢٦ من ٢٦**

**كلُّ فجوةٍ تدخل الآن بوصفها اختباراً يسقط باسمها** — **فلا تُنسى.**

| المجموعة | الفجوات | العدد | الحالُ في المنظومة |
|---|---|---|---|
| **الإشعاراتُ والروابط** | `XG-5`…`XG-9` | ٥ | `EXPECTED_FAIL` |
| **المالُ والعمولة** | `XG-10`…`XG-16` | ٧ | `EXPECTED_FAIL` |
| **المندوبُ والملكيّة** | `XG-17` · `XG-18` | ٢ | `EXPECTED_FAIL` |
| **الدعمُ والتدقيقُ والوسائط** | `XG-19`…`XG-21` | ٣ | `EXPECTED_FAIL` |
| **التدخّلُ الاستثنائيّ** | `XG-22`…`XG-24` | ٣ | `NOT_IMPLEMENTED` |
| **اللقطةُ الماليّة** | `XG-25`…`XG-28` | ٤ | `EXPECTED_FAIL` |
| **مكافأةُ الهدف** | `XG-29` · `XG-30` | ٢ | `EXPECTED_FAIL` |

```
26 CONTRACT GAPS MAPPED = 26/26
```

**وحين يُبنى أيٌّ منها يتحوّل اختبارُه إلى `PASS` بلا أن يكتب أحدٌ شيئاً
جديداً** — **وهذا هو الغرضُ من كتابته الآن.**

# ٤٨ · الفشلُ المتوقَّع

## ثلاثةُ أوسمة

```
EXPECTED_FAIL(D20)       ← عيبٌ معروفٌ مجمَّد
NOT_IMPLEMENTED(XG-23)   ← عقدٌ معتمدٌ لم يُبنَ
BLOCKED_BY(D13)          ← لا يُختبَر قبل إصلاحِ غيره
```

## القاعدة

```
اختبارٌ متوقَّعُ السقوط ينجح  ⇒  FAIL أيضاً.
```

**فحين يُصلَح `D20` ويمرّ اختبارُه وهو موسومٌ `EXPECTED_FAIL`، يسقط البناءُ
ويقول: «أزلِ الوسمَ — العيبُ أُصلح.»** **وإلّا بقيت الأوسمةُ إلى الأبد
وصار السجلُّ يكذب.**

## وبعضُ المتوقَّع مانعُ إصدار

| الوسم | أيمنع الإصدار؟ |
|---|---|
| `EXPECTED_FAIL(D13)` | **✅ نعم** — **خصوصيّةٌ مكشوفة** |
| `EXPECTED_FAIL(D20)` · `(D21)` | **✅ نعم** |
| `EXPECTED_FAIL(XG-10)` · `(XG-11)` | **✅ نعم** — **مالٌ يخرج مرّتين** |
| `NOT_IMPLEMENTED(XG-23)` | **❌ لا** — **عقدٌ مستقبليّ** |
| `EXPECTED_FAIL(XG-8)` | **⚠️ قرارُ مالك** — **رابطٌ عميقٌ ناقص** |

**والبوّابةُ تعرف الفرق** — §١٢.
