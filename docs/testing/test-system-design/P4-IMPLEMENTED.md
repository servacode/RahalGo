> **٢٠٢٦-٠٩-٠٥ · المرحلةُ الرابعة.**

# ١ · السؤالُ الذي يجيب عنه

> **كلُّ وحدةٍ ماليّةٍ لها مصدرٌ معروفٌ ووجهةٌ معروفةٌ وقيدٌ معروف، ولا
> تُخلَق ولا تضيع ولا تُحتسَب مرّتين.**

**ولا يُجاب بـ`balance == expected`.** الرصيدُ يقول ما فيه ولا يقول من أين
جاء، **ومحفظتان خاطئتان بفرقٍ متساوٍ تُخفيان بعضَهما.**

## وملاحظةٌ واحدةٌ خرجت من القياس

**وهي مادّةُ ملاحظةٍ لا حكم.**

# ٧ · `FI-06.a` — **قانونُ الحفظ الأكبر، مشتقٌّ لا مخترَع**

```
صافي كلِّ قيود الطلب في الدفتر  =  النقدُ الذي بيد السائق عنه
```

## الاشتقاق

قيودُ طلبٍ مسلَّم: الزبونُ `−wallet_paid` · المتجرُ `+due` · السائقُ
`+delivery_fee` · المندوبُ `+c` · **والخزينةُ** `delta = (wallet_paid +
cash_due) − refunded − toParties` (`treasury.go:146`). فالمجموع:

```
−wp + الأطراف + (wp + نقد − 0 − الأطراف)  =  النقد
```

**والاستردادُ لا يكسرها**: `creditTreasury` تُعيد الحسابَ بعد العكس فتقرأ
ما بقي مقيَّداً. **وأُثبت:**

```
بعد التسليم : صافي الدفتر = 2000 · نقدُ الصندوق = 2000
بعد الاسترداد: صافي الدفتر = 1500 · نقدُ الصندوق = 1500
```

## ⚠️ وصياغتي الأولى كانت ناقصةً — **والقاعدةُ صحّحتني**

**سقط الفحصُ على طلبٍ `pending`**: صافيه `−wallet_paid` ونقدُه صفر.
**ولم يكن ذلك خرقاً** — **الخزينةُ لا تُحاسِب قبل الاستلام**، فالمالُ
المدفوعُ مسبقاً محبوسٌ ولم يُنسَب بعد.

**فقُسمت الحياةُ بموضع المحاسبة**، ولم يُضيَّق الاستعلامُ ليمرّ:

| الفحص | متى | ما يقوله |
|---|---|---|
| **`FI-06.a`** | **بعد أن تُحاسِب الخزينة** | `صافي الدفتر = النقد` |
| **`FI-06.d`** | **قبلها** | `صافي الدفتر = −wallet_paid` **ولا قيدَ آخر** |

**وهذا أقوى من ثابتٍ واحدٍ يستثني نصفَ الطلبات** — **واستعلامٌ يُضيَّق
ليمرّ لا يحرس شيئاً.**

# ١٧ · قياسُ الفرق — **ولماذا لزم**

**ثوابتُ المال عامّةٌ بطبعها**: «لا محفظةَ سالبةٌ **في القاعدة**».
**وهو الصوابُ على قاعدة تشغيل** — وهو ما يشغّله `moneycheck`.

**لكنّ قاعدةَ الاختبار مقبرةُ سيناريوهات**: بعضُها يُفسد عمداً،
**وبعضُها ينظّف مستخدماً فيجرّ حذفُه قيودَه بالتتالي** فيبقى طلبٌ مسلَّمٌ
بلا مستحقِّ متجر. **فيسقط سيناريو بذنبِ غيره.**

**والحلُّ ليس إضعافَ الاستعلام** — **بل تصويرَ ما هو مخروقٌ قبل، فما ظهر
بعدُ هو ما أحدثه هذا السيناريو وحدَه.**

```sql
SELECT conname, confdeltype FROM pg_constraint
WHERE conrelid = 'wallet_transactions'::regclass AND contype = 'f';
⇒ wallet_transactions_user_id_fkey | c      -- ON DELETE CASCADE
```

**فاختبارٌ ينظّف مستخدمَه يمحو قيودَه معه** — **ويبقى الطلبُ وحدَه**:
طلبٌ مسلَّمٌ بلا مستحقِّ متجر، ورصيدٌ لا يطابق دفتراً مُحي، وصندوقٌ فارغُ
القيود. **ولا عيبَ منتجٍ في شيءٍ من ذلك.**

**وهو بعينه ما أوجب قياسَ الفرق** (§١٧): **الصيغةُ المطلقةُ لموضعها على
قاعدةِ تشغيل**، **والفرقُ لموضعه في اختبار.**

```
MONEYCHECK ON A PRODUCTION DATABASE = الصيغةُ المطلقة
MONEYCHECK ON A TEST DATABASE       = يُقرأ بالفرق لا بالمطلق
```

**ولم يُضعَّف استعلامٌ ليصمت** — **والأداةُ تقول ما ترى.**
