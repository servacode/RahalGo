# ٣٩ · معيارُ الدليل

## القاعدة

```
لا PASS بلا دليلٍ لما يحتاج دليلاً.
```

**ودُفع ثمنُ هذا فعلاً**: **كُتب `LINT = PASS` و`turbo lint` نفّذ صفرَ
مهامّ** (`TIG-4`) — **وكُتب `BUILD = PASS` وشاشةُ الإعدادات مكسورةٌ في
الإنتاج.**

## الدليلُ المطلوبُ لكلّ طبقة

| الطبقة | الدليلُ الأدنى |
|---|---|
| **`L1` وحدة** | **اسمُ الاختبارِ ونتيجتُه** — **ولا شيءَ زائد** |
| **`L2` خدمة** | **مثلُها** |
| **`L3` قاعدة** | **+ حالُ الجداول قبلَ وبعد · وحالُ الدفتر** |
| **`L4` باب** | **+ الطلبُ والردُّ كاملين** |
| **`L5` عقود** | **+ الحمولةُ الملتقَطة · وجدولُ الخصوصيّة المطبَّق** |
| **`L6` متصفّح** | **+ لقطةُ شاشةٍ عند السقوط · وأخطاءُ الطرفيّة** |
| **`L7` جهاز** | **+ `logcat` · ومعلوماتُ الجهاز · وبصمةُ الحزمة** |
| **`L8` طرفٌ لطرف** | **+ الإشعاراتُ الملتقَطةُ · وأحداثُ البثّ · وخطُّ الطلب الزمنيّ** |
| **`L9` حقنُ عطل** | **+ نقطةُ الإسقاطِ المحقونة · والحالُ الباقية** |
| **`L10` حِمل** | **+ `p50/p95/p99` · ونسبةُ الخطأ · والموارد** |
| **`L11` أمن** | **+ الطلبُ والردُّ · والدورُ المستعمَل** |
| **`L12` إصدار** | **+ الكلُّ · وبصماتُ البناء** |

## ما لا يُقبَل دليلاً

**«يعمل»** · **بناءٌ ناجح** · **سجلُّ خادمٍ نظيف** · **رمزُ حالةٍ `200`** ·
**وجودُ صنفٍ في CSS.**

**وأربعتُها الأخيرةُ ادّعيتُها فعلاً** — **والخامسُ كان صحيحاً ولم يكن
كافياً.**

# ٤٠ · هويّةُ التشغيل

**كلُّ تشغيلٍ يكتب سجلَّ هويّةٍ قبل أن يبدأ:**

```yaml
run_id:          RUN-2026-09-05-0001
mode:            IMPACTED | FULL | RELEASE | ...
source_commit:   26f93c5d
backend_image:   sha256:...
web_image:       sha256:...
apk_sha256:      ...
app_version:     0.2.3 (6)
server_version:  ...
environment:     ci | integration | staging | device-lab
device:          SM-A525F · Android 14
test_suite_ver:  ...
started_at:      ...
ended_at:        ...
result:          PASS | FAIL | PARTIAL
```

**وسببُ وجوده مقيسٌ لا مفترَض**: **بُني إصدارٌ ونُشر إصلاحٌ بعده، ولولا
البصماتُ لاختلط ما فُحص بما نُشر.**

# ٤٢ · تجميدُ مرشَّح الإصدار

```
RELEASE CANDIDATE = التزامٌ + صورةُ محرّكٍ + صورةُ ويبٍ + بصمةُ حزمةِ أندرويد + لقطةُ إعدادات
```

## القاعدة

```
لا يُفحَص بناءٌ ويُنشَر بناءٌ آخرُ ويُقال إنّه نجح.
```

**والبوّابةُ تقارن بصماتِ ما نُشر ببصماتِ ما فُحص** — **واختلافُ بايتٍ
واحدٍ يُبطل النتيجة.**

**ولقطةُ الإعدادات جزءٌ من الهويّة** — **فمنصّةٌ بعمولةٍ صفرٍ ليست المنصّةَ
التي فُحصت.**

# ٣٧ · اختبارُ الحِمل

## أحمالٌ مقترَحة

| الحِمل | لماذا |
|---|---|
| **إنشاءُ طلبات** | **ذروةُ المساء** |
| **تصفّحُ السوق** | **أثقلُ قراءة** |
| **رفعُ مواقع السائقين** | **أعلى تردّدٍ في المنصّة** |
| **نشرُ العروض** | **`ops` + كلُّ السائقين معاً** |
| **وصلاتُ البثّ** | **كلُّ التطبيقات مفتوحة** |
| **الإشعارات** | **بثٌّ عامّ** |
| **لوحةُ الإدارة** | **استعلاماتٌ ثقيلة** |
| **المحفظةُ والدفتر** | **التسويةُ لحظةَ الذروة** |

## المقاييس

`p50` · `p95` · `p99` · **نسبةُ الخطأ** · **وصلاتُ القاعدة** ·
**المعالجُ والذاكرة** · **تأخّرُ الطابور.**

## ⚠️ ولا أرقامَ قبولٍ من عندي

**لا `SLO` معتمدٌ في المشروع** — **فالاختباراتُ تقيس وتسجّل خطَّ أساسٍ ولا
تحكم.** **ووضعُ عتبةٍ من عندي يعني أن يسقط الإصدارُ برقمٍ اخترعتُه أنا.**
**وهو `TQ-3` في §١٤.**

# ٣٨ · اختبارُ النقع

**تشغيلٌ طويلٌ (٢٤–٧٢ ساعة) في بيئة التجهيز يكشف ما لا تكشفه دقيقة:**

| ما يُرصد | العلامة |
|---|---|
| **تسرّبُ ذاكرة** | **نموٌّ مطّردٌ بلا هبوط** |
| **تسرّبُ وصلاتِ بثّ** | **عددٌ يزيد ولا ينقص** — **`R14`: وصلةٌ لا تُراجَع** |
| **نموُّ طابور** | **مواقعُ لا تُستهلَك** |
| **جلساتٌ شائخة** | **`sessions` تتراكم** |
| **سقوطُ عامل** | **الراصدُ يتوقّف صامتاً** |
| **تسرّبُ وصلاتِ قاعدة** | **المسبحُ ينفد** |

**وأخطرُها في هذه المنصّة تسرّبُ وصلات البثّ** — **لأنّ `R14` يقول إنّ
الوصلةَ لا تُراجَع بعد المصافحة أبداً.**

# ٥٣ · التقرير

**كلُّ تشغيلٍ كبيرٍ يُنتج تقريراً واحداً بالشكل نفسِه:**

```
RUN-2026-09-05-0001  ·  mode=FULL  ·  commit=26f93c5d  ·  env=ci

  PASS          412
  FAIL            3
  EXPECTED_FAIL  38   ← بأسماء الفجوات والعيوب
  BLOCKED         5   ← اعتماديّةٌ غائبة
  NOT_RUN        21   ← خارجَ نطاق الوضع

  FAIL:
    F-14/financial_invariant   → الخزينةُ لا تتّزن   → D5
    F-08/concurrency           → قبولان نجحا        → R10
    privacy/merchant/realtime  → 16 حقلاً تسرّبت     → D20

  EXPECTED_FAIL (عيّنة):
    XG-10 عكسُ عمولة المندوب · XG-12 الحجز · XG-25…28 اللقطة · SG-5 دعمُ المندوب

  EVIDENCE: runs/RUN-2026-09-05-0001/
  DEFECTS:  D5 · D10 · D20
  RISKS:    R10
```

**والفرقُ بين `FAIL` و`EXPECTED_FAIL` هو ما يمنع البناءَ الأحمرَ بلا معنى**
— **والبوّابةُ وحدَها تقرّر أيُّ `EXPECTED_FAIL` مانعُ إصدار.**
