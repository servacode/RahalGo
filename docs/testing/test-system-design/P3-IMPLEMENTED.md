# ملاحظةٌ خارجَ السجلّات

```
XOB-10 — لا ساعةَ محقونةٌ في شيفرة الإنتاج
```

**`time.Now()` تُنادى مباشرةً في المحرّك** — **فلا يستطيع اختبارٌ أن يزيح
الزمنَ إلّا بتقديم البيانة** (`created_at` وأخواتها).
**وهو آمنٌ وحتميٌّ وكافٍ لـ`R8` والموقعِ الشائخ** — **ولا يكفي لمهلةٍ تُقاس
داخلَ العمليّة.**
**ولا تُجمَّد** — مادّةُ قرارٍ، **وإصلاحُها تعديلُ منتجٍ واسع.**

`XOB-9` **يبقى مؤجَّلاً إلى `P-4`** — **والمصنعُ لا يفتح باباً لأنواعه
الأربعة في الأثناء** (`allowedLedgerKind`).
