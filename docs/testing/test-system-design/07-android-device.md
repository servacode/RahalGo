# ٢٢ · موتُ العمليّة

**والأداة**: `adb shell am kill <pkg>` — **يقتل العمليّةَ ويبقي المهمّة**،
**وهو ما يفعله النظامُ تحت الضغط.**

| التطبيق | الحالُ المحفوظُ المطلوب | الاختبار | اليوم |
|---|---|---|---|
| **الزبون** | **السلّة** | **أصنافٌ ثمّ قتلٌ ثمّ عودة** | يُقاس |

| | **تتبّعُ الطلب** | **يعود إلى الطلب لا إلى الرئيسيّة** | يُقاس |

# ٢٣ · الخلفيّةُ والسبات — **للسائق خاصّة**

| الحالة | الأمر | ما يُثبَت |
|---|---|---|
| **الخلفيّة** | `am start` لتطبيقٍ آخر | **الخدمةُ الأماميّةُ تبقى** |
| **الشاشةُ مطفأة** | `input keyevent 26` | **الموقعُ يستمرّ** |
| **السبات** | `dumpsys deviceidle force-idle` | **الرحلةُ لا تضيع** |
| **توفيرُ البطّاريّة** | `settings put global low_power 1` | **إنذارٌ يُعرَض** |
| **إذنُ الموقع يُسحب** | `pm revoke` | **رسالةٌ واضحةٌ لا انهيار** |
| **GPS مطفأ** | `settings put secure location_mode 0` | **تحذيرٌ · ولا تنتهي الورديّةُ تلقائيّاً** |
| **انقطاعُ الشبكة** | `svc data disable` · `svc wifi disable` | **الطابورُ يتراكم** |
| **عودتُها** | `enable` | **يُرفَع ولا يُكرَّر** |
| **إعادةُ الإقلاع** | `reboot` | **`START_STICKY`** — **`D18` بفترة الافتراض** · **`R17` بلا سؤالٍ عن الورديّة** |

**والعقدُ المحروس**: **ضعفُ GPS لا ينهي ورديّةً ولا طلباً.**

# ٢٤ · منظومةُ اختبار الموقع

**تسعةُ مدخلاتٍ حتميّةٍ تُغذّى إلى المرشّحات مباشرةً** — **بلا جهازٍ ولا
قمرٍ صناعيّ:**

| المدخل | ما يجب أن يقع |
|---|---|
| **GPS جيّد** | **يُقبَل** |
| **دقّةٌ سيّئة** | **يُرفَض أو يُوسَم** |
| **قديم** | **يُرفَض** |
| **طابعٌ مستقبليّ** | **يُرفَض** — **`R20`** |
| **قفزةٌ مستحيلة** | **يُرفَض** — **موقعٌ مزيَّف** |
| **حركةٌ بطيئة** | **يُقبَل ويُنعَّم** |
| **ثابت** | **لا يُغرق الطابور** |
| **تبديلُ مزوّد** | **لا انقطاع** |
| **بلا GPS** | **تدهورٌ لطيف** |

**والوحداتُ المستهدَفة**: `GpsQuality` · `BearingTracker` · `PathSmoother` ·
**والطابورُ ورفعُ الدفعات** — **وهي `L1` إلّا الطابورَ فهو `L7`.**

# ٢٥ · منظومةُ اختبار الملاحة — **نوعان لا واحد**

## أ · إعادةٌ حتميّة — `L1`/`L7`

**آثارٌ ثابتةٌ تُعاد فتُنتج النتيجةَ نفسَها.**
**سريعةٌ وتُشغَّل في كلّ `PR`.**
**والقائمُ اليوم**: `qa/route_nav_test.go` · `reroute_test.go` ·
`nav_bearing_test.go` — **بذرةٌ تُوسَّع.**

## ب · جهازٌ حقيقيّ — `L7` **قبولٌ نهائيّ**

**ولا تُقبَل الإعادةُ وحدَها دليلاً** — **قلتَها، والقياسُ يؤيّدها**:
**اختبارُ الإعادة ٢٠٢٦-٠٩-٠٤ أثبت ستّةَ بنودٍ من أربعةَ عشر، والثمانيةُ
الباقيةُ لم تظهر إلّا على الجهاز.**

| البند | إعادة | جهاز |
|---|---|---|
| **المسارُ الأوّل** | ✅ | ✅ |
| **الحركةُ الحيّة** | ⚠️ | **✅ إلزاميّ** |
| **مطابقةُ المسار** | ⚠️ | **✅ إلزاميّ** |
| **متابعةُ الكاميرا** | ❌ | **✅ إلزاميّ** |
| **المسافةُ الباقية** | ✅ **تُحسب** | **✅** — **`OBS-D8`: تُعرَض الإجماليّة** |
| **الزمنُ المتوقَّع** | ✅ | ✅ |
| **الوصول** | ✅ | ✅ |
| **الخروجُ عن المسار** | ✅ | ✅ |
| **إعادةُ التوجيه** | ✅ | ✅ |
| **مرحلةُ المتجر ← الزبون** | ✅ | ✅ |
