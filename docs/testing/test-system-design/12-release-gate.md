# الشدّةُ وبوّابةُ الإصدار

> §٤٩ · §٥٠ من طلب المالك.

---

# ٤٩ · نموذجُ الشدّة — **واحدٌ للمنصّة كلِّها**

| الشدّة | التعريف | أمثلةٌ من سجلّنا |
|---|---|---|
| **`BLOCKER`** | **مالٌ يُخلَق أو يضيع · أو خصوصيّةٌ تُخترَق · أو وصولٌ غيرُ مصرَّحٍ به · أو طلبٌ يعلَق بلا مخرج** | **`D13` سردُ الوسائط · `D20` تسرّبُ البثّ · `D21` هاتفُ السائق · `XG-11` استردادٌ يفشل · `D5` مصروفٌ بلا خصم** |
| **`CRITICAL`** | **حركةٌ ماليّةٌ مضاعفةٌ محتملة · أو فقدُ حالةٍ لا يُصلَح إلّا بيدٍ في القاعدة · أو تعطّلُ تدفّقٍ أساسيّ** | **`D2` تحويلٌ جزئيّ · `R10` قبولان · `D7` سقفُ نقد · `XG-10` عمولةٌ لا تُعكَس** |
| **`HIGH`** | **عقدٌ معتمدٌ مكسورٌ يُرى للمستخدم · أو تدقيقٌ غائبٌ لفعلٍ حسّاس** | **`D22` بثٌّ غائب · `XG-5`/`XG-6` إشعاراتُ المتجر · `AG-1` جغرافيا بلا تدقيق** |
| **`MEDIUM`** | **تجربةٌ ناقصةٌ لا تمنع العمل · أو أثرٌ يُكتشَف متأخّراً** | **`XG-8` الرابطُ العميق · `D1` حدثٌ ناقص** |
| **`LOW`** | **تجميلٌ أو تنظيفٌ أو نظافةُ شيفرة** | **`R2` دوالُّ يتيمة · `OBS-A2` صفحةٌ ناقصة** |

## القاعدةُ الفارقة

```
تسرّبُ خصوصيّةٍ = BLOCKER دائماً — ولو لم تعرضه الواجهة.
إشعارٌ لم يصل    = HIGH  — إلّا إن كان الفعلُ نفسُه يعتمد عليه.
```

**وهذه القاعدةُ الثانيةُ هي ما يفرّق `R23` (دفعٌ فاشل — `HIGH`) عن `R21`
(متجرٌ لا يعلم بطلبٍ قَبِله — `CRITICAL`)**: **الأوّلُ رنّةٌ ضاعت، والثاني
التزامٌ لا يعلم به صاحبُه.**

# ٥٠ · بوّابةُ الإصدار

## القاعدةُ الأولى

```
البوّابةُ لا تُقرَّر بشعورٍ ولا بنسبةٍ مئويّة.
```

**ولا `Score` وحدَه يُجيز إصداراً** — **٩٧٪ نجاحٍ مع تسرّبِ خصوصيّةٍ واحدٍ
تعني `NO`.**

## المعايير

```
READY FOR PRODUCTION = YES  إذا وفقط إذا:

  BLOCKER مفتوحة                       = 0
  CRITICAL مفتوحة                       = 0   (أو مقبولةٌ صراحةً بقرارٍ مكتوب)
  الثوابتُ الماليّةُ الـ١٥               = PASS
  عقودُ الخصوصيّة (٤ أدوارٍ × ٤ قنوات)  = PASS
  الصلاحيّاتُ (١٣٦ باباً × ٦ أدوار)     = PASS
  حالاتُ الطلب (٥٥ + ١٤١)               = PASS
  قبولُ الجهاز الحقيقيّ                  = PASS  مع دليل
  الملاحةُ على جهازٍ حقيقيّ              = PASS  ولا يكفي الإعادة
  خطُّ الأداء الأساسيّ                   = مقيسٌ ولا انحدارَ فادح
  بوّابةُ الجاهزيّة التشغيليّة (AQ-5)     = READY أو READY WITH WARNINGS
  المخاطرُ المقبولةُ                     = موقَّعةٌ بقرارٍ مكتوب
  مرشَّحُ الإصدار                        = بصماتُه تطابق ما فُحص
```

## وحسابُ اليوم — **لو شُغّلت الآن**

| المعيار | اليوم |
|---|---|
| **`BLOCKER` مفتوحة** | **≥ ٥** — `D5` · `D13` · `D20` · `D21` · `XG-11` |
| **الثوابتُ الماليّة** | **١٣ من ١٥ مبنيّةً · واثنتان لم تُبنَيا** |
| **عقودُ الخصوصيّة** | **لم تُبنَ** — **وثلاثةُ خروقٍ مُثبَتة** |
| **قبولُ الجهاز** | **جزئيّ** — **٦ من ١٤ بنداً في الملاحة** |
| **بوّابةُ الجاهزيّة** | **لم تُبنَ** |

```
READY FOR PRODUCTION = NO
```

**وهذا ليس حكماً على المنصّة** — **بل ما تقوله البوّابةُ بالبيانات التي
لدينا.** **ولم يُطلَب منّي هذا الحكمُ بعد، وأكتبه ليُعرَف موضعُنا من الخطّ.**
