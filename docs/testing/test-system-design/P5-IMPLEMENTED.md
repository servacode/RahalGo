# ٤ · دليلُ التداخل — **عدٌّ لا ساعة**

```
HARNESS TRUE-OVERLAP SELF-TEST = PROVEN
SLEEP-BASED CONTROL            = NO
```

**والدليلُ من طرفين** (`TestCONC_ProbeMeasuresOverlap`):

```
OVERLAPPING  ⇒ تداخلٌ مقيسٌ = 2     (اثنان محبوسان داخل النافذة)
SEQUENTIAL   ⇒ تداخلٌ مقيسٌ = 1     (كلٌّ يخرج قبل أن يدخل الآخر)
```

**فلو ردَّ `2` دائماً لكان عدّاداً لا مِسباراً.**

## ⚠️ وساعةُ الجدار لا تصلح دليلاً — **وقِيس ذلك**

**كان تقاطعُ النوافذ في التوكيد الأوّل**، فسقط الاختبارُ ورأيتُ:

```
تداخلٌ مقيسٌ = 2 · تقاطعُ النوافذ = 0s
```

**والاثنان محبوسان داخل النافذة فعلاً.** **ودقّةُ ساعةِ ويندوز أخشنُ من
زمن الممثّلين** (نحو ٠٫٥–١٥ms)، **فتُقرأ البدايةُ والنهايةُ رقماً واحداً.**

**فصار الحكمُ بالعدّ** — **ووقتُ الجدار يُطبَع للاستئناس لا للحكم.**

## والقاعدةُ تشهد بنفسها

```
TRUE OVERLAP PROOF — أ ممسكٌ بالقفل · وب محجوبٌ عليه (1 جلسة)
both reached barrier → release → both entered target window
```

**وجلسةٌ محجوبةٌ على قفلٍ تحمله جلسةٌ أخرى لا تكون إلّا والاثنتان حيّتان
في اللحظة نفسِها** — **فهذا دليلٌ لا يُقاس بساعة.**

## والمهلةُ تُثبَت بالسقوط
