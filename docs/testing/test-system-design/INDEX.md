# المبادئُ الخمسة

**١ · لا حقيقةَ مكرّرة.** **وثائقُ المنتج مصدرُ الحقيقة، ومنها يُولَّد
`TEST_TRUTH`.** **ومن كتب عدداً بيده في مكانين خلق تناقضاً ينتظر.**

**٢ · يُبنى على ما هو قائم.** **`internal/qa` فيه مِسنَدٌ عاملٌ (٤٨١ سطراً)
و٢٠ ملفَّ اختبار** — **بينها التزامنٌ ومنعُ التكرار والمالُ والعقود.**
**ولا يُهدَم ما يعمل.**

**٣ · الدليلُ قبل الحكم.** **لا `PASS` بلا دليلٍ لما يحتاج دليلاً** —
**والبناءُ الناجحُ ليس دليلاً على التصميم، والسجلَّ النظيفُ ليس دليلاً على
المتصفّح.** (**دُفع ثمنُ هذا في `TIG-4`.**)

**٤ · الفشلُ المتوقَّعُ يُعلَن ولا يُخفى.** **٢٦ فجوةَ عقدٍ تدخل بوصفها
`EXPECTED_FAIL` باسم الفجوة** — **فلا تُنسى ولا تُحمّر البناءَ بلا معنى.**

**٥ · العيبُ لا يُغلَق بالإصلاح وحدَه.**

```
DEFECT FIXED + REGRESSION TEST PASS + IMPACTED TESTS PASS  ⇒  DEFECT CLOSED
```
