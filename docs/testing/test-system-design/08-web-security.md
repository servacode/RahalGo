# ٢٧ · منظومةُ اختبار لوحة الإدارة

**الحالُ اليوم: صفرُ اختبارِ متصفّح.** **وهي أكبرُ فجوةِ طبقةٍ في المشروع.**

| المجال | ما يُختبَر | الأولويّة |
|---|---|---|
| **الدخول** | **بوّابةٌ خفيّةٌ · دورٌ · فشل** | **BLOCKER** |
| **الأدوار** | **ما يراه `ops` و`finance` ولا يراه غيرُهما** | **BLOCKER** |
| **الإعدادات** | **١١٨ مفتاحاً · الشبكةُ · البحثُ · `showWhen` · الحفظُ · التحقّق** | **CRITICAL** |
| **الطلبات** | **قائمةٌ · تفصيلٌ · تدخّلٌ · خطٌّ زمنيّ** | **CRITICAL** |
| **الحسابات** | **إنشاءٌ · أدوارٌ · تعليقٌ · كلمة** | **CRITICAL** |
| **المتاجر** | **قبولٌ · تعليقٌ · قائمةٌ · ساعات** | HIGH |
| **السائقون** | **نقدٌ · تسويةٌ · إنهاءُ ورديّة** | HIGH |
| **المندوبون** | **مرشَّحون · تحويل** | HIGH |
| **السحوبات** | **قرارٌ · ولفُّ منع التكرار** | **BLOCKER** |
| **الخزينةُ والدفتر** | **قيدٌ يدويٌّ · تصدير** | **BLOCKER** |
| **التدقيق** | **قبلَ وبعد** | HIGH |
| **الدعم** | **تذكرةٌ · ردٌّ · حلٌّ بتعويض** | HIGH |

**والاستجابةُ ليست أولويّةً الآن** — **إلّا ما يمنع الاستعمال.**

**والأداة**: **متصفّحٌ آليٌّ خارجَ المستودع** — **لا يدخل حزمةَ الإنتاج ولا
يُلتزَم ولا يبدّل اعتماديّاتِ المشروع.**
**والحسابُ حسابُ QA مؤقّتٌ لا حسابُ المالك** — **قرارٌ معتمدٌ ٢٠٢٦-٠٩-٠٥.**

# ٢٨ · اختباراتُ الصلاحيّات

## القاعدة

```
تُختبَر الأبوابُ لا الواجهة. وإخفاءُ بندٍ من القائمة ليس منعاً.
```

## المصفوفة

**١٣٦ باباً إداريّاً × الأدوارُ الستّة** — **تُولَّد من الموجّه لا تُكتب.**

| الدور | ما يجب أن يُقبَل | ما يجب أن يُردّ |
|---|---|---|
| **`admin`** | **الكلّ** | — |
| **`ops`** | **القراءةُ والتدخّلُ التشغيليّ** | **الأدوارُ · اللافتاتُ · الأقسام** |
| **`finance`** | **المالُ والتقارير** | **الأدوارُ · الأقسام** |
| **`merchant`** · **`driver`** · **`sales`** | **لا شيءَ من `/admin`** | **الكلُّ — ١٣٦** |
| **بلا رمز** | — | **الكلّ** |
| **رمزٌ منتهٍ** | — | **الكلّ** |
| **رمزٌ مُبطَل** | — | **الكلّ** — **`R16`** |

**والحالةُ التي تكشف `OBS-A1`**: **`ops` ينادي `PUT /admin/settings/sales.commission_percent`
⇒ يُقبَل اليوم.** **والاختبارُ يوثّقها `EXPECTED_FAIL` حتّى تُبنى `AQ-1`.**

# ٣١ · اختبارُ التغطية

| الحالة | ما يُثبَت |
|---|---|
| **داخلَ التغطية** | **المتاجرُ تظهر · والتوصيلُ ممكن** |
| **خارجَها** | **رسالةٌ واضحةٌ لا قائمةٌ فارغة** |
| **على الحدّ** | **قرارٌ حتميٌّ لا متذبذب** |
| **تداخلُ مناطق** | **أقربُها مركزاً** — **السلوكُ القائم** |
| **متجرٌ يخدم أو لا** | **مفهومٌ غيرُ موجود** — **`EXPECTED_FAIL`** |
| **تبديلُ نصف القطر** | **⚠️ كم متجراً اختفى** — **يُقاس ويُعرَض** |

**وواجهةُ الاختبارِ تُكتب على «أيمكن التوصيلُ إلى هذه النقطة؟»** — **لا على
«أهي داخلَ الدائرة؟»** **فحين تُبنى المضلّعاتُ تُشغَّل الاختباراتُ نفسُها بلا
إعادةِ كتابة.**

# ٣٢ · اختبارُ الفروع — **مستقبليّ**

**العقدُ `AQ-2`**: **محافظة → مدينة → فرعٌ رئيسيّ → مناطقُ تشغيل → فروعٌ
فرعيّةٌ اختياريّة.**

| ما يُختبَر | لماذا |
|---|---|
| **الجغرافيا ليست فرعاً** | **`GEOGRAPHY != OPERATIONAL BRANCH`** |
| **فرعٌ رئيسيٌّ لكلّ مدينةٍ مخدومة** | — |
| **منطقةٌ تُرقّى إلى فرعٍ فرعيّ** | **بلا كسر ما فوقها** |
| **أكثرُ من فرعٍ في مدينة** | — |
| **ربطُ سائقين ومتاجرَ ومندوبين** | — |
| **تقاريرُ بالفرع** | — |

**واليومَ كلُّها `NOT_IMPLEMENTED`** — **ولا كيانَ فرعٍ في المخطّط.**
**وتُسجَّل الآن لئلّا تُنسى.**

# ٣٥ · تجريدُ مزوّد شام كاش

**واجهتان في الاختبار — ولا اختراعَ لبروتوكول:**

```
FAKE_PAYMENT_PROVIDER   ·   FAKE_PAYOUT_PROVIDER
```

**وثمانيةُ ردودٍ مكتوبةٍ سلفاً:**
`success` · `pending` · `timeout` · `duplicate_webhook` ·
`wrong_amount` · `wrong_account` · `failed` · `reversed`

**وثمانيتُها حالاتٌ عامّةٌ لأيّ مزوّد** — **فحين تصل وثائقُ شام كاش يُكتب
تنفيذٌ حقيقيٌّ خلفَ الواجهة نفسِها، وتُشغَّل الاختباراتُ نفسُها.**

```
EXTERNAL CONNECTOR = PENDING PROVIDER DETAILS
```
