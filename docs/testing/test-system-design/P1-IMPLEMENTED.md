# الحقيقةُ الواحدة

`push`. **ولا قائمةٌ لكلّ قناةٍ تنحرف عن أختها** — **وهو سببُ `D20` بعينه.**

**والحقولُ تُقرأ بالانعكاس من `orders.Order`**:

```go
func OrderFields() []string {
    t := reflect.TypeOf(orders.Order{})

}
```

**فلا قائمةَ مكتوبةٌ تشيخ بصمت** — **ومن أضاف حقلاً ظهر في الحال.**

# الانحدارات — **`EXPECTED FAIL` وليست `PASS`**

## `D21` — هاتفُ السائق يصل الزبون

```
EXPECTED FAIL / BLOCKED BY D21 — 6 خرقاً في حمولة الزبون
```

## ⚠️ وكشف الاختبارُ خمسةً لم تكن معروفة

**`D21` سُجّل على `driver_phone` وحدَه** — **والقياسُ وجد ستّةً:**

| الحقل | المرجع |
|---|---|
| **`driver_phone`** | **`D21` — معروف** |
| `platform_commission` | **`RQ-7` — ربحُ المنصّة الداخليّ** |
| `commission_percent` | **`RQ-7` — نسبتُها الداخليّة** |
| `merchant_net` | **مستحقُّ المتجر** |
| `driver_id` | **معرّفٌ داخليّ** |
| `proof_meters` | **قياسٌ تشغيليٌّ على السائق** |

**والخمسةُ تحت بند العقد**: «**ولا يرى أيَّ بياناتٍ تشغيليّةٍ داخليّةٍ غيرِ
لازمة**».
**ولا أجمّدها ولا أوسّع `D21`** — **تُعرَض ملاحظةً** `XOB-8`.

## `D20` — البثُّ يتجاوز تنقيةَ المتجر

```
REST     : 2 خرقاً
REALTIME : 24 خرقاً
EXPECTED FAIL / BLOCKED BY D20 — البثُّ يسرّب 22 حقلاً زيادةً على REST
```

**والاثنان في REST هما `platform_commission` و`commission_percent`** —
**`redactForMerchant` لا تمحوهما، والعقدُ يمنعهما.** **ملاحظةٌ ثانيةٌ ضمن
`XOB-8`.**

**والاثنان والعشرون في البثّ**: **هاتفُ الزبون وعنوانُه ونقطتُه · وهاتفُ
السائق واسمُه ومعرّفُه · وإثباتُ التسليم · والمبالغُ كلُّها.**

**وحمولةُ الزبون في البثّ كذلك**: `offered_driver_name` **يمرّ فيها ويُمنع
في REST.**

## `D22` — عقدُ القناة

```
EXPECTED FAIL / BLOCKED BY D22 — العقدُ يوجب غرفةَ الزبون عند إنشاء
الطلب الخاصّ، و`custom.go:213` يبثّ ops وحدَها.
الإثباتُ التشغيليُّ (مشتركُ بثٍّ حيّ) مؤجَّلٌ إلى P-7.
```

**و`OrderChannelContract` بُني هنا** — **الغرفُ الواجبةُ لكلّ حدث.**
**ولم يُوسَّع `P-1` إلى مشتركِ بثٍّ حيّ** — **ذاك `P-7`، والبند ٦ من طلبك
يمنع التوسّع بلا داعٍ.**

# قناةُ الدفع — **نطاقٌ أُثبت لا افتُرض**

**مغلّفُ الإشعار**: `kind` · `entity` · `entity_id` — **ولا حقلَ من حقول
الطلب الخمسة والسبعين.**

```
PUSH PRIVACY CONTRACT = NOT APPLICABLE (اليوم)
```

**ويصير منطبقاً لحظةَ يحمل حقلاً من `Order`** — **والاختبارُ يمسك ذلك.**

## ⚠️ وتصادمُ أسماءٍ كشفه القياس

**`kind` اسمٌ في المغلّف واسمٌ في الطلب**: **نوعُ الإشعار** هناك و**نوعُ
الطلب** هنا.
**ولا ضررَ اليومَ** — **الحقلُ مسموحٌ للأدوار الخمسة.**
**ويُسجَّل لئلّا يُقاس يوماً بحكمِ غيرِه.**
