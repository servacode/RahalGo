# ١٧ · عقدُ الخصوصيّة — **جدولٌ واحدٌ يحكم كلَّ القنوات**

## المبدأ

**عقدُ الخصوصيّةُ بيانةٌ لا شيفرة**: **جدولٌ يقول لكلّ دورٍ ما يُسمح به وما
يُمنع** — **ويُشغَّل على القنوات كلِّها بالحلقة نفسِها.**

```yaml
entity: Order
roles:
  customer:
    allowed:   [id, number, status, total, subtotal, delivery_fee,
                driver_name, eta, address_text, lat, lng, items]
    forbidden: [merchant_id, merchant_name, merchant_logo_thumb,
                offered_driver_name, driver_phone, platform_commission]
  merchant:
    allowed:   [id, number, status, item_count, prep_minutes, accepted_at]
    forbidden: [customer_id, customer_name, customer_phone, address_text,
                lat, lng, zone_id, zone_name, driver_id, driver_name,
                driver_phone, offered_driver_name, proof_url, proof_taken_at,
                proof_meters, subtotal, delivery_fee, discount, total,
                wallet_paid, cash_due, payment_method, promo_code]
  driver:
    allowed:   [id, number, status, customer_name, address_text, lat, lng,
                instructions, cash_due, delivery_fee]
    forbidden: [customer_phone, platform_commission, merchant_price]
  rep:
    allowed:   [number, status, total, subtotal, delivery_fee, my_share,
                forfeited_share, cancel_reason]
    forbidden: [platform_commission, forfeited_commission,
                customer_name, customer_phone, driver_name, driver_phone]
```

## القنواتُ التي يُشغَّل عليها الجدولُ نفسُه

| القناة | كيف يُلتقَط | نتيجةُ اليوم |
|---|---|---|
| **REST** | **جسمُ الردّ** | **الزبون: `driver_phone` يمرّ** ⇒ **`FAIL — D21`** · **المندوب: `platform_commission` يمرّ** ⇒ **`FAIL — XG-16`** |
| **البثّ** | **مشتركٌ اختباريٌّ في الغرفة** | **المتجر: كلُّ الممنوعِ يمرّ** ⇒ **`FAIL — D20`** |
| **حمولةُ الدفع** | **`FCM` مزيّفٌ يلتقط** | **يُقاس** |
| **الدعم** | **جسمُ التذكرة** | **يُقاس** |
| **الإدارة** | **بحسب الدور** | **يُقاس بعد `AQ-1`** |

## الشكلُ التنفيذيّ

```go
func assertPrivacy(t *testing.T, role string, payload map[string]any) {
    c := privacy.Contract["Order"][role]
    for _, f := range c.Forbidden {
        if v, ok := payload[f]; ok && !isZero(v) {
            t.Errorf("خرقُ خصوصيّة: %s يتلقّى %q = %v", role, f, v)
        }
    }
}
```

**ويُنادى من `L4` و`L5` و`L8`** — **فحيثما خرجت حمولةٌ، فُحصت.**

## والحارسُ الدائم

```
حقلٌ جديدٌ في orders.Order بلا تصنيفٍ في عقد الخصوصيّة  ⇒  البناءُ يسقط
```

**فلا يُضاف حقلٌ إلى الطلب دون أن يقول من يراه** — **وهذا وحدَه يمنع
`D20` و`D21` من التكرار.**

# ١٨ · اختبارُ عقد البثّ

**لكلّ حدثٍ لحظيّ: الناشرُ · والغرفةُ · والحمولةُ · والمتلقّي · والتنقيةُ ·
والترتيبُ · والتكرارُ · وإعادةُ الوصل.**

| الحدث | الغرف | ما يُثبَت | اليوم |
|---|---|---|---|
| **إنشاءُ طلبٍ عاديّ** | `ops` · `merchant:` · `customer:` | **ثلاثتُها تصل بحمولةٍ منقّاة** | **`FAIL` للمتجر** — `D20` |
| **إنشاءُ طلبٍ خاصّ** | **`ops` وحدَها** | **غرفةُ الزبون تصل** | **`FAIL`** — `D22` |
| **انتقالُ حالة** | **أربعُ غرف** | **الحمولةُ بحسب الدور** | **`FAIL` للمتجر** |
| **دورُ السائقين** | `topicDriverQueue` · `driver:` | **من يستحقّ يصل ومن لا يستحقّ لا يصل** | **يُقاس** |
| **المحفظة** | `user:` | **صاحبُها وحدَه** | **يُقاس** |
| **تنبيهاتُ الراصد** | `ops` | **الموظّفون وحدَهم** | **يُقاس** |

## ثلاثةُ اختباراتٍ خاصّةٍ للوصلة

| الاختبار | ما يُثبت | الخطر |
|---|---|---|
| **توكنٌ ينتهي أثناء الوصل** | **تُقطَع أو تُجدَّد — لا تبقى بمنتهٍ** | **`D19`** |
| **إبطالٌ بعد المصافحة** | **تُقطَع خلال مهلةٍ معلومة** | **`R14`** |
| **Redis معطَّلةٌ ثمّ إبطال** | **لا يُعلَن نجاحٌ كاذب** | **`R16`** |

## واختبارُ عدمِ الوصول — **وهو الأهمّ**

**لا يكفي أن يصل الحدثُ لمن يستحقّ** — **يجب أن يُثبَت أنّه لا يصل لمن لا
يستحقّ.** **ومشتركٌ اختباريٌّ في غرفةٍ لا تخصّه يجب أن يبقى صامتاً.**

# ١٩ · مصفوفةُ الإشعارات

**تُشتقّ من جردِ `s.notify.*` — ٤٩ موضعاً — ولا تُكتب بيد.**

| الحقل | ما يُثبَت |
|---|---|
| **من يستقبل** | **بالمعرّف لا بالصفة** |
| **من يجب ألّا يستقبل** | **⚠️ الأهمّ** — **تطبيقُ الزبون لا يرنّ لإشعارِ مندوب** |
| **العنوانُ والنصّ** | **من المعجم لا مطبوعان** |
| **`EntityID`** | **غيرُ فارغٍ لكلّ إشعارِ كيان** |
| **الرابطُ العميق** | **يفتح الكيانَ بعينه** |
| **القناة** | **دفعٌ · لحظيٌّ · واتساب** |
| **الصوت** | **عرضُ السائق مميَّزٌ عن غيره** |
| **الإعادة** | **بعد فشلٍ عابر** |

**وعمودُ «الإعادة» كذلك** — **`R23`.**

## الالتقاط

**`FakePusher` يجمع كلَّ رسالةٍ في الذاكرة**: **المستلمُ · والتطبيقاتُ ·
والعنوانُ · والكيانُ · والبيانات.**
**فيصير الادّعاءُ**: `pusher.Only(customerID).WithEntity("order", id)` —
**ويسقط إن وصل الإشعارُ إلى غيره.**

# ٢٠ · اختباراتُ الروابط العميقة

**العقدُ**: `PUSH → APP → ROUTE → ENTITY`.
**والحالُ**: `PendingIntent → home()` **في الأربعة** — `XG-8`.

| الحالة | ما يُختبَر |
|---|---|
| **بدءٌ باردٌ** | **التطبيقُ مغلقٌ تماماً** |
| **دافئ** | **في الخلفيّة** |
| **الخلفيّة** | **حيٌّ ولا يُرى** |
| **مُسجَّلُ الدخول** | **يفتح الكيان** |
| **توكنٌ منتهٍ** | **يجدّد ثمّ يفتح — لا يُلقيه إلى الدخول ثمّ ينسى** |

**وخمستُها تُنتج `EXPECTED_FAIL — XG-8` اليوم.**
**ولا يُقبَل فتحُ الشاشة الأولى نجاحاً** — **العقدُ يقول «الكيانَ بعينه».**
