# ١٢ · منظومةُ التزامن

## القاعدة

```
السباقُ لا يُختبَر بنداءاتٍ متتابعة — بل بحاجزٍ يُطلق الخيوطَ معاً.
```

**والقائمُ اليومَ `internal/qa/parallel_test.go` — بذرةٌ تُوسَّع.**

## الشكل

```go
func race(t *testing.T, n int, fn func(i int) Res) []Res {
    start := make(chan struct{})       // الحاجز
    out := make([]Res, n)
    var wg sync.WaitGroup
    for i := range out {
        wg.Add(1)
        go func(i int) {
            defer wg.Done()
            <-start                     // كلُّهم ينتظرون
            out[i] = fn(i)
        }(i)
    }
    close(start)                        // ثمّ ينطلقون معاً
    wg.Wait()
    return out
}
```

## العشرةُ وما يُثبت في كلٍّ

| # | السباق | العدد | الثابتُ المطلوب | الخطر |
|---|---|---|---|---|
| ١ | **سائقان يقبلان طلباً** | ٢…١٠ | **واحدٌ ينجح والباقي `409`** · **ولا قيدَ ماليٍّ مضاعف** | `R10` |
| ٢ | **`max_active`** | **سقف+١** | **لا يتجاوز السقفَ ولو بواحد** | `R10` |
| ٣ | **مرشَّحان لمتجرٍ واحد** | ٢ | **واحدٌ ينجح** | `XG-18` |
| ٤ | **طلبا سحب** | ٥ | **واحدٌ معلَّقٌ لا غير** | ✅ **يُثبَّت** |
| ٥ | **استردادٌ مقابل سحب** | ٢ | **الاستردادُ يمضي** | `XG-11` |
| ٦ | **إداريٌّ مقابل تطبيق** | ٢ | **حالةٌ واحدةٌ متّسقة** | `R7` |
| ٧ | **انتقالان** | ٢ | **حدثٌ واحدٌ لا اثنان** | `R1` · `R7` |
| ٨ | **طابورُ المواقع** | ٣ دفعات | **لا نقطةَ تُمحى قبل قبولها** | `R19` · `R20` |
| ٩ | **إبطالُ جلسةٍ أثناء نداء** | ٢ | **الردُّ متّسقٌ لا نصفَ منفَّذ** | `R15` · `R16` |
| ١٠ | **تبديلُ إعدادٍ أثناء تسوية** | ٢ | **اللقطةُ تحكم** | `XQ-2` |

**والفحصُ الماليُّ يُشغَّل بعد كلّ سباقٍ منها** — **فالسباقُ الذي لا يكسر
حالةً قد يكسر دفتراً.**

# ١٣ · منظومةُ منع التكرار

**الثمانيةُ التي طلبتَها — ولكلٍّ ما يُثبت:**

| # | الحالة | المتوقَّع |
|---|---|---|
| ١ | **مفتاحٌ واحدٌ وحمولةٌ واحدة** | **الردُّ نفسُه · وترويسةُ `Idempotent-Replay`** |
| ٢ | **مفتاحٌ واحدٌ وحمولةٌ مختلفة** | **الردُّ الأوّلُ يُعاد** — **⚠️ ولا يُقارَن التوقيعُ اليوم** |
| ٣ | **نجاحٌ ثمّ إعادة** | **لا أثرَ ثانياً** |
| ٤ | **إتمامٌ ثمّ ردٌّ ضائع** | **`done = true` والردُّ محفوظ** |
| ٥ | **إعادةُ العميل** | **الردُّ المحفوظُ لا تنفيذٌ ثانٍ** |
| ٦ | **خطأٌ ثمّ إعادة** | **حُرِّر المفتاحُ فوراً · والإعادةُ تُنفَّذ** |
| ٧ | **`in_progress`** | **`409` بينما الأوّلُ يعمل** |
| ٨ | **تنظيفُ ٢٤ ساعة** | **العالقُ يُمسح كالمكتمل** |

## ولا يُنتظَر يومٌ

```sql
-- تقديمُ الزمن بتقديم البيانة لا بتقديم الساعة
UPDATE idempotency_keys SET created_at = now() - interval '25 hours' WHERE key = $1;
```

**وهذا آمنٌ وحتميٌّ** — **ولا يمسّ ساعةَ النظام ولا يفرض ساعةً وهميّةً في
شيفرة الإنتاج.**

**والحالةُ الثانيةُ تكشف شيئاً**: **المفتاحُ لا يُقرن بتوقيع الحمولة** —
**فمن أعاد بمفتاحٍ واحدٍ وحمولةٍ ثانيةٍ يأخذ ردَّ الأولى.** **ملاحظةٌ تُسجَّل
حين يُشغَّل الاختبارُ لا الآن.**

# ١٤ · حقنُ العطل

## المبدأُ الحاكم

```
الاعتماديّاتُ الخارجيّةُ خلفَ واجهات — والاختبارُ يحقن التنفيذَ العاطل.
ولا سطرَ `if testing` في شيفرة الإنتاج.
```

## ما يُسقَط وكيف

| الاعتماديّة | كيف يُحقَن | ماذا يُقاس |
|---|---|---|
| **عمليّةُ قاعدةٍ رقمُ N** | **مُغلِّفٌ على `Querier` يعدّ ثمّ يخطئ** | **ما بقي وما ارتدّ** |
| **Redis** | **عميلٌ عاطل** | **`R16` — أيُعلَن الإبطالُ كذباً؟** |
| **FCM** | **مُرسِلٌ مزيّفٌ يفشل** | **`R23` — أيُعدّ الفعلُ ناجحاً؟** |
| **واتساب** | **`SendText` يفشل** | **`R21` — أيعلم المتجر؟** |
| **SMS** | **مزوّدٌ مزيّف** | — |
| **رفعُ ملفّ** | **مخزنٌ يفشل** | **`D13` وأثرُ الإثبات** |
| **الخرائطُ والمسار** | **OSRM مزيّفٌ يتأخّر أو يفشل** | **الملاحةُ والتسعير** |
| **الراصد** | **دورةٌ تُقاطَع** | **`R22`** |
| **كتابةُ التدقيق** | **`audit_log` يفشل** | **`AQ-4` — أينجح الفعلُ صامتاً؟** |
| **مزوّدُ السحب** | **ثمانيةُ ردود** (§٤) | **الحجزُ والإطلاق** |
| **مزوّدُ الدفع** | **الثمانيةُ نفسُها** | **دفعُ الطلب** |

## الشكل

```go
h.FailAt(qa.DBWrite, 3)        // الكتابةُ الثالثةُ تسقط
h.FailAll(qa.FCM)              // الدفعُ يسقط دائماً
h.FailOnce(qa.WhatsApp)        // مرّةً ثمّ يعمل
```

**والقياسُ بعد كلّ حقنٍ خمسةٌ**: **حقيقةُ القاعدة · والمال · والإشعارُ ·
وما يراه المستخدم · وما تراه الإدارة.**

# ١٥ · اختباراتُ الفشل الجزئيّ

**التسعةُ المسجَّلة — ولكلٍّ سيناريو:**

| العملية | نقطةُ الإسقاط | ما يجب أن يبقى | ما يجب أن يرتدّ | إنذارٌ متوقَّع | مسارُ إصلاح |
|---|---|---|---|---|---|
| **`D2`** | **الكتابةُ ٤ (الكلمة)** | **المتجرُ والحساب** | **لا شيءَ اليوم** | **⛔ لا شيء** | **إعادةُ كلمةٍ يدويّة** |
| **`D2`** | **الكتابةُ ٧ (التثبيت)** | **المتجرُ والمكافأة** | **الكلُّ نظريّاً** | **⛔ لا شيء** | **وسمٌ يدويّ** |
| **`D5`** | **بين المصروف والخزينة** | **المصروف** | **المصروف** | **⛔** | **الإبطالُ قائم** |
| **`D15`** | **بين الحساب والكلمة** | **الحساب** | — | **⛔** | **إعادةُ كلمة** |
| **`R7`** | **بين الحالة والحدث** | **الحالة** | **الحدث** | **⛔** | **إسنادٌ يدويّ** |
| **`R8`** | **بعد النجاح قبل الحفظ** | **الأثرُ كاملاً** | — | **⛔** | **مهلةُ ٢٤ ساعة** |
| **`R21`** | **بين القبول والإرسال** | **القبول** | — | **⛔** | **إرسالٌ يدويّ** |
| **`R22`** | **بين الوسم والإشعار** | **الوسم** | **الوسم** | **⛔** | **مسحُ `alerted_at`** |
| **`R23`** | **فشلُ الدفع** | **الصفُّ في الصندوق** | — | **⛔** | **لا شيء** |

**وتسعٌ من تسعٍ عمودُ «إنذارٌ متوقَّع» فيها `⛔`** — **فأوّلُ ما تكشفه هذه
الطبقةُ ليس عيباً في عمليّةٍ بل غيابَ مفهومِ «عمليّةٍ لم تكتمل» في المنصّة
كلِّها** (`OBS-A6`).

**والاختبارُ يوثّق ذلك بوصفه `EXPECTED_FAIL`** — **ولا يمرّ صامتاً.**

# ١٦ · اختباراتُ التدقيق — `AQ-4`

## قاعدتان متقابلتان

```
فعلٌ حسّاسٌ نجح          ⇒  سطرُ تدقيقٍ موجودٌ بقبلَ وبعد
كتابةُ التدقيق أُسقطت    ⇒  الفعلُ الحسّاسُ لا ينجح صامتاً
```

## الأفعالُ الحسّاسة

**قيدُ محفظةٍ · استردادٌ · سحبٌ · إعدادٌ · صلاحيّةٌ · تعليقٌ · إعداداتُ متجرٍ ·
تبديلُ حساب شام كاش لاحقاً.**

## نتيجةُ الاختبار اليوم

| الفعل | القاعدةُ الأولى | القاعدةُ الثانية |
|---|---|---|
| **قيدُ المحفظة** | ✅ `finance.wallet_apply` | **`EXPECTED_FAIL`** — **`s.audit` في `goroutine` بسياقٍ منفصل** |
| **قرارُ السحب** | ✅ | **`EXPECTED_FAIL`** |
| **الإعداد** | ✅ **بقبلَ وبعد** | **`EXPECTED_FAIL`** |
| **الأدوار** | ✅ | **`EXPECTED_FAIL`** |
| **التعليق** | ✅ | **`EXPECTED_FAIL`** |
| **إعداداتُ المتجر** | **`EXPECTED_FAIL`** — `MG-6` | **`EXPECTED_FAIL`** |
| **قرارُ المرشَّح** | **`EXPECTED_FAIL`** — `AG-2` | **`EXPECTED_FAIL`** |
| **الجغرافيا (١٣ باباً)** | **`EXPECTED_FAIL`** — `AG-1` | **`EXPECTED_FAIL`** |

**فالقاعدةُ الأولى تمرّ في خمسةٍ من ثمانية، والثانيةُ تسقط في ثمانيةٍ من
ثمانية** — **لأنّ التدقيقَ بنيويّاً خارجَ المعاملة** (`XG-20`).
