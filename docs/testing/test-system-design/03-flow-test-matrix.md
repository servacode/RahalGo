# خمسةَ عشرَ مساراً لكلّ تدفّق

**ولا يُكتفى بالمسار السعيد.**

| # | المسار | ما يُثبت |
|---|---|---|
| ١ | **`HAPPY`** | **الأثرُ الكامل** في كلّ طرف |
| ٢ | **`NEGATIVE`** | **مدخلاتٌ باطلةٌ تُردّ برسالةٍ تُقرأ** |
| ٣ | **`AUTH`** | **بلا رمزٍ · برمزٍ منتهٍ · برمزٍ مُبطَل** |
| ٤ | **`PERMISSION`** | **كلُّ دورٍ لا يملكه يُردّ** — **بالباب لا بالواجهة** |
| ٥ | **`FAILURE`** | **سقوطُ اعتماديّةٍ خارجيّة** |
| ٦ | **`CONCURRENCY`** | **تنفيذٌ متوازٍ بحاجزٍ حقيقيّ** |
| ٧ | **`PARTIAL`** | **إسقاطُ خطوةٍ بعينها ثمّ قياسُ ما بقي** |
| ٨ | **`OFFLINE`** | **انقطاعٌ وعودةٌ · وطابورٌ** |
| ٩ | **`TOKEN_EXPIRY`** | **REST يجدّد · والبثُّ ماذا يفعل** |
| ١٠ | **`NOTIFY_FAIL`** | **الفعلُ ينجح والإشعارُ يسقط** |
| ١١ | **`REALTIME_FAIL`** | **القناةُ تسقط — أيُعوَّض؟** |
| ١٢ | **`IDEMPOTENCY`** | **إعادةٌ بالمفتاح نفسِه لا تُضاعف** |
| ١٣ | **`FINANCIAL`** | **الثوابتُ الأحدَ عشرَ بعد الفعل** |
| ١٤ | **`ADMIN`** | **تدخّلٌ إداريٌّ في اللحظة نفسِها** |
| ١٥ | **`RECOVERY`** | **مسارُ الإصلاح بعد الانكسار** |

**ولا يلزم كلُّ مسارٍ لكلّ تدفّق** — **قواعدُ الاشتقاق في §٢ تختار.**

# ٦ · اختبارُ خارطة الحالات

**المُدخَلُ** [`ORDER_TRANSITIONS_55.md`](../ORDER_TRANSITIONS_55.md) —
**مولَّدٌ أصلاً من `statuses.go`.**

## ما يُولَّد آليّاً من الخارطة

| الصنف | العدد | ما يُثبَت |
|---|---|---|
| **مسموحة** | **٥٥** | **كلُّ انتقالٍ مسموحٍ ينجح ويكتب حدثاً** |
| **ممنوعة** | **١٤ حالةً × ١٤ − ٥٥ = ١٤١** | **كلُّ انتقالٍ غيرِ مسموحٍ يُردّ** |
| **مكرَّرة** | **٥٥** | **الانتقالُ نفسُه مرّتين لا يضاعف أثراً** |
| **خارجَ الترتيب** | **عيّنة** | **`pending → delivered` يُردّ** |
| **تجاوزٌ إداريّ** | **بحسب الدور** | **ما يجوز للأدمن دون غيره** |
| **سباق** | **العشرةُ** | **انتقالان متزامنان** |
| **إعادة** | **بمفتاح** | **لا ازدواجَ ماليّ** |

**فمجموعُ الحالات المولَّدة ≈ ٣٠٠** — **لا تُكتب بيد، وتتبدّل مع الخارطة
نفسِها.**

**وهذا يحرس `R1`** (البوّابةُ يُلتفّ عليها في موضع) **و`D1`** (فكٌّ بلا حدث)
**و`D9`** (طلبٌ خاصٌّ بلا أوّل حدث) **و`D22`.**

## والطلبُ الخاصُّ يدخل المصفوفةَ نفسَها

**بقرار `XQ-4`**: **يُختبَر بالحرّاس الأربعة نفسِها**
(`cashBlocked` · `RequireWhatsApp` · `order_events` · `publishOrder`) —
**واختلافُه اليومَ يُنتج `EXPECTED_FAIL` باسم `D6`/`D8`/`D9`/`D22`، لا
استثناءً في المصفوفة.**
