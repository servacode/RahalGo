# خطّةُ التنفيذ — مراحلُ قابلةٌ للإغلاق

> **٢٠٢٦-٠٩-٠٥ · خطّةٌ لا تنفيذ.**
> **ولا تبدأ مرحلةٌ قبل إذنك بها** — **بنداً بنداً، لا بالموافقة على الخطّة.**

---

# المبادئُ التي رتّبت المراحل

**١ · الأصغرُ أوّلاً.** **مرحلةٌ لا تُغلَق في أيّامٍ ليست مرحلةً بل مشروعاً.**

**٢ · الأعلى عائداً قبل الأغلى.** **جدولُ الخصوصيّة ملفُّ بيانةٍ ودالّة —
ويحرس ثلاثةَ عيوبٍ مجمَّدة.**

**٣ · ما لا يعتمد على غيره أوّلاً.** **البنيةُ التحتيّةُ قبل ما يقوم عليها.**

**٤ · ولا مرحلةَ تُصلح عيباً.** **الإصلاحُ مرحلةٌ أخرى بإذنٍ آخر.**
