# RV-1 · حافّةُ منطقة التوصيل — **(U1c سابقاً)**

| البند | القيمة |
|---|---|
| **ما هو معروف** ✅ | **الطبقتان مُثبَتتان**: `ST_DWithin` (دائرةُ المدينة) للتصفّح · ومضلّعاتُ `delivery_zones` عند الإنشاء. **وقاعدةُ الجدول الفارغ**: لا مناطقَ ⇒ الباب مفتوح · مناطقُ فعّالةٌ والدبّوسُ خارجَها ⇒ `ErrOutOfZone`. **والإنتاج فيه ٤ مناطقَ فعّالة.** |
| **ما لا يُثبَت بالقراءة** | **سلوكُ النقطة على الحدّ تماماً** — `ST_Covers`/`ST_DWithin` عند صفرِ مسافة، **ودقّةُ `geography` بالأمتار.** |
| **لماذا يحتاج تشغيلاً** | **جوابُ PostGIS عند الحافّة يعتمد على دقّةِ الفاصلة العائمة وإسقاطِ `geography`** — **ولا يُقرأ من نصّ.** |
