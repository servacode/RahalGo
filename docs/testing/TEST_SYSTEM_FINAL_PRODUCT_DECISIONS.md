# `TQ-1` — **منعُ الإصدار بالشدّة لا بقائمة** · **APPROVED**

## العقد

```
SEVERITY-BASED RELEASE BLOCKING
```

**والفجوةُ تصير مانعةً إن سبّبت أو سمحت بواحدٍ من عشرة:**

**ضياعُ مالٍ · خلقُ مالٍ أو حركةٍ ماليّةٍ مضاعفة · فشلُ استردادِ زبونٍ أو
ضياعُ استحقاق · تسرّبُ خصوصيّةٍ أو بياناتٍ حسّاسة · وصولٌ غيرُ مصرَّحٍ به أو
ترقيةُ صلاحيّة · حالُ طلبٍ لا تُستردّ · فسادُ حالةٍ أساسيّةٍ بسباقٍ أو تكرار ·
تعذّرُ إتمام رحلةِ طلبٍ أساسيّةٍ بأمان · خطرٌ مباشرٌ على السلامة · خرقُ ثابتٍ
في الدفتر أو التسوية.**

**ورفضتَ القائمةَ اليدويّةَ التي عرضتُها** — **وأنت محقّ**: **ثلاثةٌ اخترتُها
بحدسي، والقاعدةُ تصنّف السّتَّ والعشرين كلَّها بلا حدس.**

## تصنيفُ السّتِّ والعشرين

### `BLOCKER` — **٦**

| ID | الفجوة | أيُّ معيارٍ يقع تحته |
|---|---|---|
| **`XG-10`** | **لا عكسَ لعمولة المندوب عند الاسترداد** | **خلقُ مال** — **المنصّةُ تدفع مرّتين على طلبٍ واحد** |
| **`XG-11`** | **الاستردادُ يفشل إن سحب المندوبُ عمولتَه** | **فشلُ استردادِ زبون** — **مالُه يُحتجَز بسبب طرفٍ ثالث** |
| **`XG-18`** | **لا فحصَ ازدواجٍ ولا قيدَ فريدٍ للمرشَّحين** | **فسادُ حالةٍ بسباق** + **حركةٌ ماليّةٌ مضاعفة** — **متجران لمتجرٍ واحدٍ ومندوبان يقبضان** |
| **`XG-21`** | **`/media/` مكشوفٌ وفيه إثباتُ التسليم** | **تسرّبُ بياناتٍ حسّاسة** — **عنوانُ زبونٍ وبابُه للعالم** |
| **`XG-22`** | **التعليقُ العاديُّ يشلّ إتمامَ طلبٍ قائم** | **تعذّرُ إتمام رحلةٍ أساسيّة** — **والبضاعةُ خرجت** |
| **`XG-29`** | **مكافأةُ الهدف تُدفع قبل تثبيت التحويل** | **خلقُ مال** — **تحويلٌ فاشلٌ يُعاد فتُدفع مرّتين** |

### `CRITICAL` — **٧**

| ID | الفجوة | لماذا ليست مانعةً |
|---|---|---|
| **`XG-14`** | **بوّابةُ `platformCommission` مثبَّتة** | **ضياعُ استحقاق** — **لكنّ الوضعَ الذي يوجبه غيرُ قابلٍ للضبط بعد** |
| **`XG-25`**…**`XG-28`** | **اللقطةُ الماليّةُ الأربع** | **الدفترُ يتّزن** — **والمالُ يُوزَّع باقتصادٍ لم يُتَّفق عليه** |
| **`XG-20`** | **التدقيقُ الحسّاسُ خارجَ المعاملة** | **لا مالَ يضيع** — **وتضيع المساءلةُ عنه** |
| **`XG-12`** | **لا طبقاتِ رصيد** | **لا ضررَ اليوم** — **والقرارُ يُخصَم عند `paid` بقفلٍ** · **⚠️ يصير `BLOCKER` لحظةَ يصير التحويلُ آليّاً** |

### `HIGH` — **٩**

`XG-5` · `XG-6` (إشعاراتُ المتجر) · **`XG-7`** (القبولُ التلقائيُّ صامت) ·
`XG-13` (مفتاحُ مصدر الاحتساب) · **`XG-15`** (عتبةُ التفعيل) ·
`XG-16` (المندوبُ يرى عمولةَ المنصّة) · `XG-17` (لا سجلَّ نقل) ·
`XG-19` (لا دعمَ للمندوب) · `XG-23` · `XG-24` (التدخّلُ الاستثنائيّ)
· `XG-30` (حالُ المكافأة).

### `MEDIUM` — **٢**

`XG-8` (الرابطُ العميق) · `XG-9` (٢٤ إشعاراً بلا توجيه).

## ⚠️ وقياسٌ غيّر تصنيفَ اثنتين

**قستُ الافتراضات قبل أن أصنّف:**

```
orders.auto_accept_min   Default: 0    ⇒  القبولُ التلقائيُّ مطفأٌ اليوم
sales.activation_orders  Default: 1    ⇒  العتبةُ مفتوحةٌ اليوم
```

**فـ`XG-7` و`XG-15` فجوتان نائمتان** — **لا أثرَ لهما ما لم يُبدّل الأدمنُ
مفتاحاً.** **ولولا القياسُ لصنّفتُهما `CRITICAL` بلا سبب.**

**وهذا يكشف صنفاً ثالثاً يلزم تسميتُه:**

```
LATENT — فجوةٌ بلا أثرٍ اليومَ، تستيقظ بتبديل إعدادٍ واحد.
```

**وثلاثٌ منها**: `XG-7` · `XG-15` · `XG-12`.
**والبوّابةُ تعاملها بشدّتها اليقظى لا النائمة** — **فلا يُطلَق بمفتاحٍ
مطفأٍ ثمّ يُشعله موظّفٌ بعد أسبوع.**

```
TQ-1 = CLOSED
BLOCKER = 6 · CRITICAL = 7 · HIGH = 11 · MEDIUM = 2   (المجموع 26)
LATENT  = 3   (تُحسَب بشدّتها اليقظى)
```

# `TQ-2` — **مصفوفةُ أجهزةِ قبولٍ متعدّدةُ المصنّعين** · **APPROVED**

```
MULTI-MANUFACTURER REAL DEVICE ACCEPTANCE MATRIX
```

**و`SM-A525F / Android 14` يبقى الجهازَ المرجعيَّ الأساسيّ** — **لا يتبدّل.**

## المصفوفة

| الفئة | تطبيقُ السائق | الثلاثةُ الباقية | لماذا |
|---|---|---|---|
| **سامسونغ الأساس** — `SM-A525F` · Android 14 | **✅ مرجعيّ** | **✅ مرجعيّ** | **كلُّ ما ثبت ثبت عليه** |
| **مصنّعٌ يقيّد الخلفيّة** — Xiaomi/Redmi | **✅ إلزاميّ** | ⚠️ **اختياريّ** | **يقتل الخدماتِ الأماميّة بسياساتٍ لا تظهر في سامسونغ** |
| **جهازٌ منخفضُ الكلفة** — Infinix/Tecno | **✅ إلزاميّ** | ⚠️ **شاشةٌ وأداء** | **الأرجحُ في يد سائقٍ في الرقّة** |
| **أندرويد أقدم** — نحو `minSdk = 26` | **✅ إلزاميّ** | **✅** | **إحدَ عشرةَ نسخةً في المدى** |
| **هواوي** | ⏸️ **عند توفّر جهازٍ أو حاجةِ سوق** | ⏸️ | **قرارُك** |

## ولماذا يأخذ السائقُ الأوسع

**تطبيقُه وحدَه يقوم على**: **خدمةٍ أماميّةٍ لا تموت · وموقعٍ في الخلفيّة ·
وسباتٍ وتوفيرِ بطّاريّة · وملاحةٍ · وموتِ عمليّةٍ · وGPS · وتعافي شبكة.**
**وسبعتُها تتبدّل بتبديل المصنّع** — **والبقيّةُ تتبدّل بتبديل النسخة والشاشة
لا أكثر.**

**والعيوبُ الأربعةُ التي تنتظر جهازاً**: `D16` · `D17` · `D18` · `R17` —
**كلُّها في السائق، وكلُّها تمسّ الخدمةَ والخلفيّة.**

```
TQ-2 = CLOSED
DRIVER MATRIX = 4 فئاتٍ إلزاميّة  ·  OTHER APPS = 2 إلزاميّة
REFERENCE DEVICE = SM-A525F / Android 14  (بلا تبديل)
```

# `TQ-3` — **قِسْ أوّلاً ثمّ ثبّت** · **APPROVED**

```
MEASURE FIRST → FREEZE EVIDENCE-BASED SLOs
```

## طورُ خطّ الأساس — **ثلاثُ دوراتٍ مستقرّة**

**يُجمَع فيها**: **`p50/p95/p99` للأبواب · وإنشاءُ الطلب · وتحميلُ المتجر
والطلب · وإسنادُ السائق · والبثُّ · ورفعُ المواقع · والإشعاراتُ · ولوحةُ
الإدارة · والقاعدةُ والمعالجُ والذاكرةُ · وتأخّرُ الطابور · وإقلاعُ أندرويد
واستجابةُ الملاحة.**

**وبعد ثلاثِ دوراتٍ تُعتمَد أهدافٌ رسميّةٌ لكلّ تدفّقٍ حرج.**

## القاعدةُ المؤقّتة

```
انحدارٌ > ٢٠٪ عن خطّ الأساس المستقرّ  ⇒  تحقيقٌ لا إسقاطٌ آليّ
```

**وتدفّقٌ حرجٌ صار غيرَ قابلٍ للاستعمال فعلاً يمنع الإصدارَ ولو بلا هدفٍ
رسميّ.**

**وهذا يحلّ ما اعترضتُ عليه بالضبط**: **لن أُسقط إصداراً برقمٍ اخترعتُه** —
**والبابُ يبقى مفتوحاً لمنعِ ما لا يُستعمل.**

```
TQ-3 = CLOSED
BASELINE CYCLES REQUIRED = 3
INTERIM RULE = 20% regression ⇒ investigate
```

# `TQ-4` — **سيرفرُ تجهيزٍ مستقلّ** · **APPROVED**

```
DEDICATED SECOND INTEGRATION/STAGING SERVER
NO WRITING TESTS AGAINST PRODUCTION DATABASE
```

**ومنفصلٌ في**: **الموارد · والقاعدة · وRedis · والملفّات · والعمّال ·
وحسابات الاختبار · والمزوّدين المزيّفين.**

## ولماذا هذا هو الصواب — **قياسٌ لا رأي**

**سيرفرُ الإنتاج `CX33` يحمل ستَّ حاوياتٍ اليوم**: `caddy` · `api` · `web` ·
`postgres` · `redis` · `osrm`.
**وطقمٌ ثانٍ عليه يشارك الإنتاجَ معالجَه وذاكرتَه** — **واختبارُ الحِمل
يخنق زبوناً حقيقيّاً.**

**وأربعةُ أصنافٍ من الاختبار مستحيلةٌ بلا بيئةٍ مستقلّة**:

| الصنف | لماذا يستحيل على الإنتاج |
|---|---|
| **حقنُ العطل** | **إسقاطُ Redis أو FCM عمداً** |
| **التزامن** | **عشراتُ الخيوط على أبوابٍ ماليّة** |
| **الهدمُ والاسترجاع** | **مسحُ بيانات** |
| **محاكاةُ المزوّدين** | **موصِلٌ مزيّفٌ محلَّ الحقيقيّ** |

**والنقعُ (٢٤–٧٢ ساعة) خامسُها** — **يكشف تسرّبَ وصلات البثّ الذي يشير إليه
`R14`.**

```
TQ-4 = CLOSED
START = سيرفرٌ واحدٌ مستقلّ  ·  التوسّعُ لاحقاً (CI عابر · حِملٌ مستقلّ · مختبرُ أجهزةٍ أوسع)
```
