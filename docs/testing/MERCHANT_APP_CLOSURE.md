# ١ · MERCHANT JOURNEY FROM ZERO

```
تثبيت
 └─ MerchantApplication.onCreate → PushChannels.ensure
 └─ AppFrame
      ├─ UpdateGate  ← app.min_version.merchant
      ├─ BrandIntroHost
      ├─ AskStartupPermissions → POST_NOTIFICATIONS  (ولا موقعَ يُطلب)
      └─ signedIn → Push.register  ·  else → AuthScreen   (ولا ضيفَ)

الدخول → /merchant/stores → متجرٌ واحدٌ أو أكثر
 └─ الوضعُ يقرّره المحرّك: selfManage أم بوّابةُ منصّة
      ├─ selfManage = false  → تبويبُ «القائمة» يحلّ محلّ «الطلبات»
      └─ selfManage = true   → دورةُ الطلب كاملةً بيده

دورةُ الطلب:
  pending → «قبول» أو «رفض»
          → accepted → «بدء التحضير» → preparing
          → «جاهز» (ready_at) → المكتبُ يُنزله للسائقين
          → السائقُ يستلم → picked_up ← ومستحقُّ المتجر يُقيَّد
  وفي أيّ وقت: إلغاءٌ (بقيدٍ) · بلاغٌ على سائق · طوارئُ تُغلق المتجر

وبين ذلك: قائمةٌ (أصنافٌ وأقسامٌ وصورٌ وتوفّر) · دوامٌ · إعداداتُ متجر
· عنوانٌ ونقطةٌ على الخريطة · محفظةٌ وسحب · إنذاراتٌ وبلاغاتٌ عليه
· مبيعاتٌ · تاريخٌ · دردشةٌ · حساب

خروج
```

**⚠️ وما ليس في القائمة المتوقَّعة ووُجد**: **الطوارئ** (إغلاقٌ فوريّ) ·
**البلاغُ على سائق** · **البلاغاتُ عليه** (`reports-against`) · **الإنذارات** ·
**شاشةُ المبيعات** · **أقسامُ المنصّة** (`platform-sections`) ·
**وضعُ «بوّابةِ منصّة» الذي يبدّل التبويبات.**

**وما ليس فيه**: **لا موقعَ حيّ · لا خريطةَ سائق · لا رقمَ زبون.**
