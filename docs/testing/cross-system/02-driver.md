# ٨ · الورديّةُ والطلبُ القائم والخروجُ والتعليق

## العقودُ المعتمدة

| العقد | الحال |
|---|---|
| **طلبٌ قائمٌ يمنع الخروج** | **عقدُ تطبيقٍ** — **ولا حارسَ في المحرّك** |
| **التعليقُ العاديُّ لا يقطع تسليماً قائماً** | ❌ **غيرُ مُنفَّذ** — **`status` يتبدّل فوراً و`RequireAuth` يردّ** |
| **التدخّلُ الاستثنائيُّ صريح** | ⚠️ **ضمنيٌّ عبر إعادةِ الإسناد** — **ولا مسارَ مسمّى** |
| **ضعفُ GPS لا ينهي الورديّةَ تلقائيّاً** | ✅ **لا شيءَ ينهيها بالموقع** |

## التفاعلُ المقيس

```
SHIFT (driver_shifts)
  ├─ يفتحها: POST /driver/shift
  ├─ ينهيها: السائق · أو الإدارة (POST /admin/drivers/{id}/end-shift ✅ مُدقَّق)
  └─ تحكم: الظهورَ في الدور · والعروضَ

ACTIVE ORDER
  ├─ يحكمه: max_active · cash_limit · الحالة
  └─ لا يُقطع بتعليقٍ — لكنّ صاحبَه يُمنع من إنهائه

LOGOUT / SUSPENSION / TOKEN REVOCATION
  ├─ HTTP: يُردّ فوراً (middleware.go:40)
  ├─ WS:   يبقى مفتوحاً (D14)
  ├─ Push: الرمزُ يبقى (D12)
  └─ Role: ١٥ دقيقة (R15)

LOCATION SERVICE
  └─ START_STICKY — تعود بفترة الافتراض (D18) · وبلا سؤالٍ عن الورديّة (R17)
```

## ⚠️ الفجوةُ الكبرى

**سائقٌ عُلّق وبيده طلبٌ**: **الطلبُ يبقى مُسنَداً إليه** · **وHTTP يردّه**
· **فلا يستطيع `at_pickup` ولا `delivered`** · **والزبونُ ينتظر** ·
**والمتجرُ سلّم البضاعة.**

**والمخرجُ الوحيد**: **إعادةُ إسنادٍ يدويّةٌ من اللوحة.**
**ولا إشعارَ للإدارة أنّ هذا وقع** — **ولا استعلامَ «طلباتٌ بيد موقوفين».**

# ٩ · الموقعُ من الجهاز إلى الخريطة

```
FusedLocation
  → ترشيحٌ في الجهاز (دقّةٌ · سرعةٌ · قفزة)
  → طابورٌ محلّيّ (ملفّ)
  → POST /driver/location  أو  /driver/location/batch
  → users.last_location + last_location_at   (0072)
  → حالُ الرحلة والملاحة في الجهاز
  → ❌ لا بابَ إداريّاً يقرؤه
  → ❌ لا خريطةَ في اللوحة
```

| العيب/الخطر | الأثرُ عبر المنظومة |
|---|---|
| **`D16`** | **طابورُ المواقع ملفٌّ بلا صاحب** — **سائقٌ يخرج وآخرُ يدخل على الجهاز نفسِه ⇒ نقاطُ الأوّل تُرفَع باسم الثاني** |
| **`D17`** | **الملاحةُ لا تعود بعد موت العمليّة** — **رحلةٌ قائمةٌ وشاشةٌ فارغة** |
| **`D18`** | **`START_STICKY` يعيد الخدمةَ بفترةِ الافتراض** — **لا بفترةِ الإعداد** |
| **`R17`** | **الخدمةُ تعود بلا سؤالٍ عن الورديّة** — **خصوصيّةٌ وبطّاريّة** |
| **`R18`** | **الرفعُ لا يُجدّد التوكن** — **دفعةٌ تسقط عند انتهاءٍ أثناء الرفع** |
| **`R19`** | **`all → شبكة → clear` بلا قفل** — **نقاطٌ تُمحى قبل أن تُرسَل** |
| **`R20`** | **مسحُ الدفعة بلا قراءة `accepted`** — **ساعةُ جهازٍ متقدّمةٍ تُسقط نقاطاً** |

## وأثرُ ذلك على `XPRQ-1`

**البيانةُ موجودةٌ منذ `0072`** — **`last_location` و`last_location_at`
بفهرس `gist`.**
**والناقصُ بابٌ وشاشة** — **وهو أرخصُ مراحل الخريطة** (`AQ-6` المرحلةُ ١).

**لكنّ `D16` يمسّ صحّةَ البيانة نفسِها**: **نقطةٌ قد تكون لسائقٍ آخر.**
**فالخريطةُ إن بُنيت قبل إصلاحه تعرض حقيقةً مشكوكاً فيها.**

## وما يبقى غيرَ مثبَت — **ولا يُعدّ `PASS`**

**الحركةُ الحيّة · مطابقةُ المسار · متابعةُ الكاميرا · المسافةُ الباقية ·
الزمنُ المتوقَّع · الخروجُ عن المسار · إعادةُ التوجيه.**

**وسببُ عدم الإثبات مقيسٌ لا مفترَض**: **اختبارُ الإعادة ٢٠٢٦-٠٩-٠٤ أثبت
ستّةَ بنودٍ وترك ثمانية** — **والخريطةُ ظهرت بيضاءَ لأنّ `files/maps/state`
فارغ، وتحتَه `FALLBACK_REGION = "raqqa"` ليس في الفهرس.**

**والأثرُ عبر المنظومة**: **`OBS-D8`** — **`TripPanel.kt:178` يعرض
`state.routeM` (إجماليَّ المسار من الخادم) بدل الباقي** — **فالزبونُ يُخبَر
بزمنٍ لا يتقلّص.**
