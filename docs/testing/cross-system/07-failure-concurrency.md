# ٣١ · كلُّ ما يتحرّك بلا إنسان

**جُرد المحرّكُ**: **حلقةٌ دوريّةٌ واحدةٌ تحمل ثلاثةَ أفعال، وحلقتان
مساعدتان.**

## `RunWatchdog` — `orders/watchdog.go:86`

```go
ticker := time.NewTicker(interval)
for {
    select {
    case <-ctx.Done(): return
    case <-ticker.C:
        s.SweepExpiredOffers(ctx)   // ١
        s.sweepAutoAccept(ctx)      // ٢
        alerts, _ := s.Alerts(ctx)  // ٣
        if key == lastKey { continue }
        s.pub.Publish("ops", ...)
        s.escalate(ctx, alerts)
    }
}
```

| # | الفعل | يقفل؟ | ينقل حالة؟ | يُشعر؟ | يُدقَّق؟ | يعيد؟ | فشلٌ جزئيّ |
|---|---|---|---|---|---|---|---|
| ١ | **`SweepExpiredOffers`** | ❌ **قراءةٌ ثمّ حلقة** | ✅ **ينقل العرضَ للتالي** | ✅ **بثٌّ ودفع** | ⚠️ **`ops` لا `audit_log`** | **الدورةُ التالية** | ⚠️ **عرضٌ يُسحب وآخرُ لا يُعطى** |
| ٢ | **`sweepAutoAccept`** | ❌ **`LIMIT 50` بلا `FOR UPDATE`** | ✅ **`pending → accepted`** | ⚠️ **الزبونُ نعم · المتجرُ لا** | ⚠️ **`ops.order_transition`** | **الدورةُ التالية** | ⚠️ **يمرّ على واحدٍ ويسقط في آخر** |

## ⚠️ `XOB-5` — **مفتاحُ المقارنة قد يبتلع إنذاراً**

```go
key := ""
for _, a := range alerts { key += a.OrderID + a.Reason + "|" }
if key == lastKey { continue }
```

**طلبٌ يخرج وآخرُ يدخل بالسبب نفسِه في الدورة نفسِها ⇒ مفتاحٌ مطابق ⇒ صمت.**
**وأضيقُ من `R22` وأدقُّ منه** — **`R22` عن `alerted_at`، وهذا عن المقارنة
قبلها.**

## ⚠️ `XOB-6` — **الوسمُ قبل الإشعار**

```go
UPDATE orders SET alerted_at = now() WHERE id = $1 AND alerted_at IS NULL

```

**فإن سقط الإشعارُ بقي الوسم — ولا إنذارَ ثانٍ أبداً.**

يُمسح كالمكتمل** · **عند أوّل نداءٍ لأيّ بابٍ محميٍّ من أيّ مستخدم.**
