# ١٧ · تعليقُ المتجر — `PC-11`

**العقدُ**: **التعليقُ العاديُّ يمنع طلباتٍ جديدةً ولا يقطع القائمة.**

| الطبقة | ما يقع |
|---|---|
| **الهويّة** | **`users.status` للمالك** — **و`merchants.status` للمتجر** · **حقلان لا واحد** |
| **تطبيقُ المتجر** | **الأبوابُ تُردّ إن عُلّق حسابُ المالك** |
| **السوق** | **المتجرُ يختفي من التصفّح** |
| **الطلباتُ القائمة** | ⚠️ **لم يُثبَت** — **`POST /merchants/{id}/suspend` يمسّ `merchants` ولا يمسّ الطلبات** |
| **السائق** | **يُكمل** — **الطلبُ حالتُه لا تتبدّل** |
| **الزبون** | **يُكمل** |
| **البثّ** | ⚠️ **`D14`: قناةُ المالك تبقى مفتوحة** |
| **التدقيق** | ✅ `ops.merchant_suspend` |

**فالعقدُ مستوفىً ظاهراً** — **والحالةُ لا تُقطَع.**
**والفجوةُ في اللوحة لا في المحرّك**: **لا تمييزَ بين «تعليقٍ عاديّ»
و«تدخّلٍ استثنائيّ»** — **حقلٌ واحدٌ لا نوعان** (`XQ-5`).

# ١٨ · تعليقُ السائق

**العقدُ**: **العاديُّ مؤجَّلٌ حتّى تنتهي الطلباتُ القائمة** ·
**والاستثنائيُّ مسارٌ صريحٌ بإعادةِ إسنادٍ أو إلغاء.**

| ما يوجبه العقد | الحال |
|---|---|
| **تعليقٌ مؤجَّل** | ❌ **لا مفهومَ «مؤجَّل»** — **`status` يتبدّل فوراً** |
| **الطلبُ القائم** | ⚠️ **يبقى مُسنَداً** — **والسائقُ يُردّ في HTTP فلا يستطيع إنهاءه** |
| **مسارُ تدخّلٍ صريح** | ⚠️ **موجودٌ ضمنياً**: `POST /orders/{id}/assign` لسائقٍ آخر · **ولا زرَّ «تدخّلٌ استثنائيّ»** |
| **البثّ** | ❌ **`D14` يبقى مفتوحاً** |
| **الأثرُ الماليّ** | ⚠️ **نقدُه في صندوقه** — **و`cash/outstanding` يراه** |
| **إنهاءُ الورديّة** | ✅ `POST /drivers/{id}/end-shift` — **مُدقَّق** |

**والأثرُ عبر المنظومة**: **زبونٌ ينتظر طلباً بيد سائقٍ لا يستطيع تسليمَه** —
**والمتجرُ سلّم البضاعةَ فعلاً.** **ولا مسارَ يُغلق هذا إلّا بإعادةِ إسنادٍ
يدويّة.**

# ٣٨ · الصلاحيّاتُ عبر الطبقات

| الطبقة | ما تحرسه | الحال |
|---|---|---|
| **الواجهة** | **بنودُ القائمة** — `roles: ["admin"]` في `layout.tsx` | ✅ **قائمة** |
| **الباب** | **`RequireRoles`** | ⚠️ **مجموعةٌ عامّةٌ + استثناءات** |
| **الخدمة** | **لا شيء** | ❌ **لا فحصَ صلاحيّةٍ في طبقة الخدمة إطلاقاً** |

## والأدوارُ القائمةُ ستّةٌ لا تسعة

```
customer · driver · merchant · sales · ops · finance   (+ admin)
```

**والعقدُ `AQ-1` يطلب تسعةَ أدوارٍ وظيفيّة** — **ولا `support` ولا
`trust/safety` ولا `marketing` ولا `analytics`.**

## ⚠️ ثلاثةُ فجواتٍ عبر المنظومة

| # | الفجوة | الدليل |
|---|---|---|
| **١** | **الإعداداتُ الحسّاسةُ مفتوحةٌ للأدوار الثلاثة** | **`PUT /admin/settings/{key}` بلا `RequireRoles("admin")` داخليّ** — **ونسبةُ العمولة بيد `ops`** |
| **٢** | **اللافتةُ الإعلانيّةُ محروسةٌ أكثرَ من نسبةِ العمولة** | `POST /admin/banners` **بـ`admin`** · **والإعدادُ بلا** |

يقبل.**
