# ٢٤ · الدعمُ من طرفٍ إلى طرف

## القاعُ موحَّدٌ والأعلى ثلاثةُ مداخل

```
tickets(number UNIQUE من 501 · customer_id NOT NULL · order_id · reason
        · status open/in_progress/resolved · compensation · resolution)
ticket_replies(ticket_id · author_id · body · created_at)
```

| الدور | المدخل | الحال |
|---|---|---|
| **الزبون** | `support.Complaint` → `POST /my/orders/{id}/complaint` | ✅ |
| **السائق** | `support.DriverReport` → `POST /driver/orders/{id}/report` | ✅ |
| **المتجر** | `support.MerchantReport` → `POST /merchant/orders/{id}/report` | ✅ |
| **المندوب** | ❌ **لا دالّةَ ولا باب** | ❌ |

**والثلاثةُ القائمةُ كلُّها تشترط `orderID`.**

## الفرقُ بين القائم والعقد

| البند | الحال | العقد |
|---|---|---|
| **رقمُ مرجع** | ✅ | ✅ |
| **تصنيف** | ⚠️ **`reason` من قائمةٍ مغلقةٍ لكلّ دور** | **شجرةٌ لكلّ دور** |
| **وصف** | ⚠️ **`subject` يُبنى في الخادم** | **حقلٌ حرّ** |
| **مرفقات** | ❌ | ✅ **وتنتظر `D13`** |
| **كيانٌ مرتبط** | ⚠️ **`order_id` وحدَه** | **طلبٌ · متجرٌ · مرشَّحٌ · سحبٌ · أو لا شيء** |
| **حال** | ✅ **ثلاثةٌ** | ✅ |
| **أولويّة** | ❌ **لا عمود** | ✅ |
| **إسنادٌ لموظّف** | ❌ **لا عمود** | ✅ |
| **ردُّ الإدارة** | ✅ | ✅ |
| **ردُّ المستخدم** | ❌ **البابُ في مجموعة الإدارة** | ✅ |
| **قراءةُ تذكرةٍ واحدة** | ❌ **قائمةٌ فقط** | ✅ |
| **تدقيقٌ وتاريخ** | ⚠️ **الحلُّ مُدقَّق · الإنشاءُ والردُّ لا** | ✅ |

```
CENTRAL SUPPORT GAPS = 8   (SG-1…SG-6 + الأولويّة + الإسناد)
```

**والعمودُ `customer_id NOT NULL` يحمل صاحبَ التذكرة أيّاً كان دورُه** —
**فالاسمُ زبونيٌّ والمعنى عامّ.**

# ٢٥ · التغطيةُ من طرفٍ إلى طرف

## العقدُ

```
Delivery Address  >  Browse Location  >  Device Location
والتوصيلُ الفعليُّ أهمُّ من المدينة ونصف القطر
```

## والحالُ يناقضه في أساسه

```
موقعُ الزبون
  → city_filter.go:87 : مدينةُ المتجر == مدينةُ الزبون
  → cities: مركزٌ + نصفُ قطر (دائرة)
  → delivery_zones: مركزٌ + نصفُ قطر (دائرة)
  → ❌ لا مضلّعَ في المنظومة كلِّها
  → ❌ لا فحصَ «أيمكن التوصيلُ فعلاً»
```

**والمضلّعُ حُذف صراحةً** — `0009_invite_codes_circle_zones.sql:13`:

```sql
ALTER TABLE delivery_zones DROP COLUMN polygon;
ALTER TABLE delivery_zones ADD COLUMN center geography(Point,4326) NOT NULL;
```

**و`governorates` و`districts` أسماءٌ بلا هندسةٍ إطلاقاً.**

## و«اطلب تغطية منطقتي»

| الطبقة | الحال |
|---|---|
| **جدولُ `coverage_requests`** | ❌ |
| **بابٌ للزبون** | ❌ |
| **شاشةُ إدارة** | ❌ |
| **عدٌّ وتحليل** | ❌ |
| **خريطةُ حرارة** | ❌ |
| **مسارُ قرار** | ❌ |

**والبنيةُ الوحيدةُ القابلةُ لإعادة الاستعمال**: **`districts` قائمةٌ مرتّبةٌ
موثوقة** — **فالطلبُ يُنسَب إلى ناحيةٍ لا نقطةٍ عائمة، فتصير العدّةُ ذاتَ
معنى.**

## ⚠️ خطرُ نصف القطر

**تبديلُ `city.radius_m` يُخفي متاجرَ من سوق الزبائن** — **فعلٌ صامتٌ واسعُ
الأثر** · **بلا تدقيقٍ** (`AG-1`) **وبلا إشعارٍ وبلا معاينةِ أثر.**

# ٢٦ · الفروعُ والجغرافيا — `AQ-2`

## الهرمُ المطلوبُ مقابل القائم

| المطلوب | القائم |
|---|---|
| **محافظة → مدينة → فرعٌ رئيسيّ → مناطقُ تشغيل** | **محافظة → ناحية → مدينة** |

**والدليلُ عمودٌ واحد** — `0122_governorates_districts.sql:100`:

```sql
ALTER TABLE cities ADD COLUMN IF NOT EXISTS district_id uuid REFERENCES districts(id);
```

## أثرُ الانقلاب

| المجال | الأثر |
|---|---|
| **الاستعلامات** | **التجميعُ بالفرع يحتاج عكسَ اتّجاه المفتاح** |
| **التقارير** | **«أداءُ الفرع» غيرُ ممكنٍ اليوم** |
| **التغطية** | **دوائرُ متداخلةٌ في مستويين ولا حدودَ حقيقيّة** |
| **الفروع** | **لا كيان** |
| **تجميعُ المتاجر** | **`merchants.city_id` + `district_id` — حقلان لطبقتين متعاكستين** |
| **تجميعُ السائقين** | ❌ **لا ربطَ إطلاقاً** |
| **نشاطُ المندوب** | ⚠️ **مُشتقٌّ من متاجره** |
| **خريطةُ العمليّات** | **الطبقةُ الرابعةُ محجوبةٌ كاملةً** |

```
BRANCH MODEL GAPS = 10
```

# ٣٧ · مُدخلاتُ بوّابة الجاهزيّة — `AQ-5`

**ولا تُبنى الآن** — **وهذه قائمةُ ما يجب أن تقيسه من منظور المنظومة.**

## `CRITICAL BLOCKER` ⇒ `NOT READY`

| الشرط | كيف يُقاس اليوم |
|---|---|
| **عمولةُ المنصّة أو نسبةُ المندوب أو الهامشُ صفرٌ ثلاثتُها** | **قراءةُ ثلاثة مفاتيح** |
| **لا مدينةٌ نشطةٌ ولا منطقةُ توصيل** | **عدُّ `cities` و`delivery_zones` النشطة** |
| **لا حسابَ `admin` نشط** | **عدُّ `user_roles`** |
| **قاعدةٌ أو Redis غيرُ سليمة** | **`/healthz` قائم** |
| **`D13` مفتوح** | **مخزنُ الوسائط مكشوف** |

## `WARNING` ⇒ `READY WITH WARNINGS`

| الشرط |
|---|
| **لا متجرَ نشطٌ في مدينةٍ مفعَّلة** |
| **واتساب غيرُ مقترنٍ** — `GET /admin/whatsapp` |
| **لا سائقَ في ورديّةٍ منذ مدّة** |
| **مفاتيحُ حسّاسةٌ لم تُبدَّل قطّ** — **`updated_at IS NULL`** |
| **مرشَّحون معلَّقون فوق عتبة** |
| **`payouts.min_amount` أكبرُ من كلّ الأرصدة** |

## وما لا يمكن قياسُه اليومَ إطلاقاً

**صحّةُ قناةِ الدفع** (**لا حالَ تسليم**) · **موصِلُ شام كاش** (**لم يُبنَ**)
· **تغطيةٌ حقيقيّةٌ بمضلّعات** (**لا مضلّعات**) · **فروعٌ مضبوطة** (**لا
كيان**).

**فالبوّابةُ حين تُبنى ستقيس ما هو موجودٌ وتصمت عمّا ليس موجوداً** —
**وهذا وحدَه سببٌ لبنائها متأخّرةً بعد النماذج، لا قبلها.**
