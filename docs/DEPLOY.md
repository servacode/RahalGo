# النشرُ على خادم رحّال غو

> **المنصّةُ على خادمها منذ ٢٠٢٦-٠٨-١٥** — ولا استضافةَ جاهزةَ بعد اليوم.
> وما كان في هذا المستند عن `Render` **حُذف**: تلك تجربةٌ انتهت، **ومستندٌ
> يصف ما لا نفعله يُتَّبع يوماً فيُكسر ما يعمل.**

---

| `https://rahalgo.com` | الويب — الموقعُ ولوحةُ الإدارة والبوّابات |
| `https://api.rahalgo.com` | المحرّك — وتطبيقاتُ الجوّال تناديه |
| `195.201.141.130` | الخادم — Hetzner CX33 · Nuremberg · Ubuntu 24.04 |

**وستُّ حاويات**: بوّابةٌ (Caddy) · محرّكٌ (Go) · ويبٌ (Next) · قاعدةٌ
(PostGIS) · ذاكرةٌ (Redis) · مساراتٌ (OSRM بخريطة سوريا).

**ولا منفذَ مكشوفٌ إلّا ٢٢ و٨٠ و٤٤٣** — والقاعدةُ والذاكرةُ والمساراتُ
على شبكةٍ داخليّة. **ومنفذُ قاعدةٍ مكشوفٌ للإنترنت يُمسح خلال ساعات.**

## النشرةُ الجديدة

```bash
ssh root@195.201.141.130
cd /srv/rahalgo
# تُحدَّث الشيفرة (نسخاً أو من المستودع)، ثمّ:
cd deploy
docker compose build api    # المحرّك
docker compose build web    # الويب
docker compose up -d
```

**وتُبنى واحدةً واحدةً لا معاً**: بناءُ الويب وبناءُ المسارات في وقتٍ
واحدٍ يستهلكان الذاكرةَ كلَّها **فيموت عاملُ Next برسالةٍ لا تقول
السبب** (`build worker exited with code 1`). قِيس ٢٠٢٦-٠٨-١٥.

**والمسارات لا تُبنى إلّا مرّةً** — أو حين تُحدَّث خريطةُ سوريا.

## مزالقُ قُيست — لا تُكرَّر

**١ · `node_modules` من ويندوز لا تدخل الصورة.** pnpm يربط الحزمَ
بروابطَ رمزيّة، **وروابطُ ويندوز لا تُقرأ في لينكس** — فتُحلُّ أنواعُ
الحزم المشتركة إلى `any` **ويسقط البناءُ في ملفٍّ سليم.** ويمنعه
`web/.dockerignore`.

**٢ · وحزمُ المشروع تُنقل مع حزم التطبيق.** `COPY --from=deps /app /app`
لا `node_modules` التطبيق وحدَها — **وإلّا قال المترجم «لا أجد react»
في كلّ ملفٍّ من `packages`.**

**٣ · و`NEXT_PUBLIC_*` تُمرَّر مرّتين**: وسيطَ بناءٍ (تُستبدَل في
الشيفرة) **ومتغيّرَ تشغيل** — `next start` يقرأ الإعدادَ من جديدٍ عند
الإقلاع فيسقط إن لم يجدها.

**٤ · و`OTP_PROVIDER=dev` يرفضه المحرّكُ في الإنتاج** — ومحقٌّ: يطبع
رموزَ الدخول في السجلّ. **والقيمةُ `whatsapp`.**

**٥ · وشهادةُ Let's Encrypt تحتاج نداءً مباشراً** — فتبقى سجلّاتُ
Cloudflare **رماديّةً (`DNS only`)** حتّى تُصدَر. ويُشغَّل الوكيلُ
البرتقاليُّ بعدها إن أُريد.

**٦ · وHetzner تخنق SSH من عناوين مراكز البيانات** — ومن يعمل خلف VPN
تُسقَط اتّصالاتُه بعد بضعٍ منها. **وتُفتح جلسةٌ واحدةٌ تحمل كلَّ
الأوامر** لا جلسةٌ لكلّ أمر.

## بعد أوّل إقلاع

**١ ·** ادخل من `/login` بالرقم وكلمةِ المرور المؤقّتة ← **يُطلب تبديلُها
وضبطُ رمز أدمن (٤ أرقام).**

**٢ · ثمّ تُحذف `ADMIN_PASSWORD` من `deploy/.env`** — **وكلمةٌ تبقى في
ملفٍّ على الخادم مفتاحٌ حيٌّ لمن قرأه.**

**٣ · واقترن بالبوت**: الإعدادات ← بوت واتساب ← «ربط الجهاز» ← امسح
الرمز. **وبلاه لا يصل رمزُ تحقّقٍ إلى أحد.**

## الأسرارُ ومواضعُها

**كلُّها في `/srv/rahalgo/deploy/.env`** بصلاحيّة `600`: كلمةُ القاعدة ·
سرُّ التوقيع · رقمُ الأدمن. **ولا تُكتب في المستودع ولا في `compose.yml`.**

**والحجومُ تبقى بعد كلّ نشرة**: `pgdata` (القاعدة) · `uploads` (الصور)
· `caddy_data` (الشهادات) · `redisdata`.
