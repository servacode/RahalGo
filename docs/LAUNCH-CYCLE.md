# الدورةُ التشغيليّةُ الكاملة — **شهادةُ جاهزيّة الإطلاق**

> **طلبه المالكُ نصّاً (٢٠٢٦-٠٩-٢٩):** «فحصُ المشروع كاملاً وإنشاءُ ملفٍّ للدورة
> التشغيليّة بشكلٍ كامل… بحيث نختبر كلَّ شيءٍ بالمشروع ونقول فعلاً إنّ المنصّة
> جاهزةٌ للإطلاق والعمل بشكلٍ حقيقيّ.»
>
> **بُني من الشيفرة لا من الوثائق** — مسحٌ للمحرّك (`backend/`) والويب
> (`web/apps/rahalgo`) والتطبيقات الأربعة (`mobile/`) والنشر (`deploy/`).
> كلُّ بندٍ يشير إلى مسارٍ أو إعدادٍ موجودٍ فعلاً اليوم.

## ٠ · القاعدةُ التي تحكم هذا الملفّ

**المنصّةُ جاهزةٌ حين — وفقط حين — تتحقّق الشروطُ الأربعة:**

1. **كلُّ عوائق القسم ١ مُغلقة** (مُصلَحةٌ باختبارٍ رآه المُصلحُ ساقطاً ثمّ ناجحاً، أو بقرارٍ موقَّعٍ من المالك بقبول الخطر).
2. **كلُّ بندٍ في الأقسام ٣–١٤ عليه ✅ ودليل** — لا «يبدو أنّه يعمل».
3. **`go run ./cmd/moneycheck` صفرُ مخالفات** بعد كلّ يومٍ من أيّام التجربة، وبعد التجربة الميدانيّة.
4. **سبعةُ أيّامٍ ميدانيّةٍ متتالية** (القسم ١٥) بلا عطلٍ من درجة «حرِج».

**وكلُّ بندٍ يُسجَّل بثلاثة:** من نفّذه · متى · الدليل (رقمُ الطلب / قيدُ الدفتر / سطرُ السجلّ / ناتجُ الأمر).

| الرمز | المعنى |
|---|---|
| ⬜ | لم يُختبر |
| ✅ | نجح — والدليلُ مكتوب |
| ❌ | سقط — ويُفتح له بندٌ في القسم ١ |
| ⏸ | مؤجَّلٌ بقرار المالك (يُكتب السبب) |

## ٢ · بيئةُ الدورة

### أ · أين تُجرى

**على التجهيز (staging)** — `deploy/staging/` — بنسخةٍ مطابقةٍ لما سيُنشر:

- [ ] `stagingctl guard` يمرّ، و`/api/v1/public/identity` يقول `environment=staging` وبنفس الـcommit المرشَّح للإنتاج.
- [ ] `stagingctl backup` قبل البدء، ثمّ `stagingctl reset` ⇒ قاعدةٌ نظيفة.
- [ ] `OTP_PROVIDER` — **مرّةً `dev` للدورة الآليّة، ومرّةً `whatsapp` حقيقيّاً** لدورة الأجهزة (القسم ١١).
- [ ] FCM مضبوطٌ (`FCM_CREDENTIALS_FILE`) — وإلّا لا يُختبر أيُّ إشعار.
- [ ] `OSRM_URL` و`GEOCODER_URL` و`MAP_TILE_URL` تشير إلى خوادمنا — **لا إلى OSM العامّ** (يُحظر تحت الحِمل).

### د · مثالُ الحساب الذي تُقاس عليه كلُّ الدورة

صنفٌ واحد: **سعرُ شراء المتجر 10,000**، وبالإعدادات أعلاه:

| البند | المبلغ |
|---|---|
| سعرُ البيع للزبون (10,000 + هامش 1,000) | 11,000 |
| رسمُ التوصيل | 5,000 |
| **يدفع الزبون** | **16,000** |
| مستحقُّ المتجر (10,000 − عمولة 10%) | 9,000 |
| أجرُ السائق | 5,000 |
| نصيبُ المندوب (20% من الهامش 1,000) — **إن كان المتجرُ مفعَّلاً** | 200 |
| **ربحُ المنصّة** (هامش 1,000 + عمولة 1,000 − مندوب 200) | **1,800** |

**والتحقّقُ:** 16,000 = 9,000 + 5,000 + 200 + 1,800.
