## السجل التفصيلي

### 2026-07-30 — بوت واتساب + جدول الإعدادات الديناميكية + أساس لوحة الأدمن 🔄
- **بوت واتساب (whatsmeow)**: جلسة مخزنة في PostgreSQL، حلقة اتصال خلفية بتراجع أسّي
  (انقطاع واتساب لا يمنع إقلاع الخادم)، اقتران QR (سجل + نقطة أدمن)، قالب الرسالة
  ديناميكي من app_settings — **اختُبر حياً: اتصل بخوادم واتساب وولّد QR حقيقياً**.
- **app_settings** (هجرة 0003): مخزن الإعدادات الديناميكية المركزي.
- **لوحة الأدمن (Next.js 15 + React 19)**: شاشة دخول RTL بالهوية المعتمدة، عميل API
  موحد بتجديد توكن تلقائي عند 401، حماية أدوار (admin/ops/finance فقط)، هيكل تنقل
  كامل، بطاقة حالة بوت واتساب، خط IBM Plex مستضاف ذاتياً (لا اعتماد على خوادم خارجية).
- **اختبار E2E بمتصفح حقيقي (Playwright + Chromium)**: عنوان وRTL صحيحان، رسالة خطأ
  مترجمة عند كلمة مرور خاطئة، دخول ناجح يحوّل للوحة، خروج يعيد للدخول — كله أخضر.

### 2026-07-30 — المرحلة 1: نظام الهوية والمصادقة الكامل 🔄
- **قاعدة البيانات** (هجرة 0002): users، roles (الأدوار السبعة مزروعة)، user_roles،
  otp_codes (مجزأة بمحاولات محدودة)، refresh_tokens (قابلة للإبطال)، audit_log.
- **المصادقة**: Argon2id لكلمات المرور، JWT وصول (15 دقيقة) بالأدوار + Refresh مبهم
  (30 يوماً) بتدوير إلزامي — إعادة استخدام توكن قديم تُرفض.
- **OTP**: توليد آمن، تجزئة HMAC، صلاحية 5 دقائق، 5 محاولات، حد معدل 3 طلبات/15 دقيقة
  لكل رقم (Redis) — عبر واجهة مزوّد مجرّدة (dev الآن، whatsapp تالياً).
- **توحيد الأرقام السورية**: 09xxxxxxxx → ‎+9639xxxxxxxx بكل الصيغ (مع اختبارات وحدة).
- **النقاط**: otp/request، otp/verify (تسجيل زبون تلقائي)، login، refresh، logout،
  me، password — ووسيطا RequireAuth وRequireRoles للـRBAC.
- **أدمن الإقلاع**: ADMIN_PHONE يُنشأ ويُمنح الدور تلقائياً.
- **سجل تدقيق** يلتقط: التسجيل، الدخول بنوعيه، ضبط كلمة المرور، التدوير، الخروج.
- **اختبار حي شامل (8 سيناريوهات)**: كلها خضراء — بما فيها الرفض الصحيح للرمز الخاطئ
  وإعادة الاستخدام والوصول بلا توكن، و429 عند تجاوز المعدل.
- المتبقي للمرحلة 1: تكامل whatsmeow الفعلي، لوحة الأدمن (Next.js)، إدارة المتاجر والمناطق.

### 2026-07-30 — المرحلة 0: الأساسات (شبه مكتملة) 🔄
- هيكل Monorepo كامل: `backend/` `web/` `android/` `docs/` + `.gitignore` + `.editorconfig`.
- **الخادم (Go)**: بنية طبقية، إعدادات بيئة، اتصالات PostgreSQL/Redis بمجمعات،
  مشغّل هجرات مضمّن (schema_migrations)، صيغة استجابة/خطأ موحدة بمفاتيح ترجمة،
  خادم HTTP بوسطاء (RequestID, CORS, Recoverer, Timeout) وإيقاف رشيق، نقطة `/healthz`.
- **تم اختباره فعلياً**: إقلاع كامل مع قواعد بيانات حية، تطبيق هجرة postgis+citext،
  فحص الصحة يرد `ok`، وصيغة الخطأ الموحدة تعمل.
- **الويب**: مساحة عمل pnpm + Turborepo، حزمة `@rahalgo/tsconfig` (strict)،
  حزمة `@rahalgo/ui` (توكنز TS + ثيم Tailwind v4 من BRAND.md)،
  حزمة `@rahalgo/i18n` (العربية أساس، RTL، بنية مشتقة النوع لأي لغة جديدة) — Typecheck أخضر.
- **Docker Compose** للتطوير (PostgreSQL+PostGIS، Redis بفحوصات صحة).
- **CI** على GitHub Actions: مساران (Go: lint+build+test، Web: typecheck+build).
- المتبقي من المرحلة 0: اعتماد اللوغو النهائي، وOpenAPI مع أول نقطة API (المرحلة 1).
