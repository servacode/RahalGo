# RahalGo — رحّال

منصة توصيل طلبات متعددة الفئات في محافظة الرقة — سوريا.

**الحزمة الكاملة**: خادم Go • واجهات ويب Next.js (زبون، أدمن/عمليات، متاجر، مندوبون) • تطبيقا أندرويد أصليان Kotlin (زبون، سائق) • بوت واتساب للتحقق والإشعارات.

## التشغيل المحلي (للتطوير والتجربة)

**المتطلبات**: [Go 1.24+](https://go.dev/dl/) • [Node 22+](https://nodejs.org) مع `corepack enable` (لتفعيل pnpm) • [Docker](https://docs.docker.com/get-docker/)

```bash
# 1) قواعد البيانات (طرفية واحدة — مرة واحدة)
docker compose up -d

# 2) زراعة بيانات التطوير (مرة واحدة — حسابات جاهزة بكلمات مرور + متاجر بقوائمها)
cd backend
go run ./cmd/seed

# 3) الخادم (نفس الطرفية أو ثانية)
go run ./cmd/api

# 4) واجهات الويب (طرفية أخرى)
cd web
pnpm install
pnpm dev     # يشغّل الواجهات كلها معاً
```

| الواجهة | الرابط |
|---|---|
| لوحة الإدارة | http://localhost:3001 |
| بوابة المتجر | http://localhost:3002 |
| موقع الزبون | http://localhost:3003 |
| لوحة المندوب | http://localhost:3004 |
| تطبيق السائق | http://localhost:3005 |

### الزراعة — وضعان

```bash
go run ./cmd/seed          # كل شيء: طاقم + متجران بقوائمهما + زبون برصيد 200000
go run ./cmd/seed -staff   # طاقم المنصة وحده: أدمن وعمليات ومالية، بلا بيانات عرض
go run ./cmd/seed -store   # متجرٌ واحد كامل وصاحبه — ولا شيء غيره
```

**`-store`** يزرع **مطعم بيت الرقة**: ستّة أقسام · ٣٢ صنفاً · ١٦ مجموعة
خيارات · ٣٩ خياراً · ساعات عمل الأسبوع (والجمعة تفتح بعد الصلاة) · وصنفٌ نفد
من المطبخ. بياناتٌ للتجربة الحقيقية لا للفحص — **والفرق بينهما الكثافة**:
متجرٌ بصنفين يُثبت أن الشيفرة تعمل ولا يُظهر كيف تبدو المنصة لزبونٍ يتصفّح.

**ومعه مندوبُه**: المتجر في هذه المنصة لا يأتي من فراغ — مندوبٌ يزوره في
السوق ويعطيه رابط دعوته، فيسجّل صاحبه، فتوافق الإدارة. ومتجرٌ بلا مندوب يُخفي
نصف الدورة: لا عمولة إحالةٍ عليه، ولا عميلَ في لوحة مندوب، ولا عتبةَ تفعيلٍ
تُختبر. فتُنشئ الزراعة الطرفين وتربطهما، وتترك **أثر الرحلة**: طلبُ انضمامٍ
مُحوَّل يشير إلى المتجر الذي وُلد منه.

| الحساب | الهاتف | كلمة المرور |
|---|---|---|
| أبو محمود الحاج علي — صاحب مطعم بيت الرقة | `0932556677` | `Matam@2026` |
| زياد العبدالله — المندوب الذي جلبه (كوده `RH-BAYT1`) | `0944778899` | `Mandoub@2026` |

> كود دعوة المندوب **لا يظهر في لوحته حتى يوثّق واتسابه** — قرارٌ سابق: أداةُ
> دعوةٍ بلا قناة تواصلٍ موثّقة تُسلَّم لمن لا يُعرف كيف يُبلَّغ.


**وضع `-staff` هو ما يلزم بعد تنظيف القاعدة**: قاعدةٌ بلا أدمن قاعدةٌ لا يُدخَل
إليها، وبقية الكيانات يصنعها صاحبها من اللوحة كما يصنعها في الإنتاج. والمناطق
والتصنيفات والإعدادات تبقى في الحالين — **بنيةُ عملٍ لا بيانات عرض**: بلا
منطقةِ توصيلٍ واحدة لا يُقبل أيّ طلب.

### اختبار الدورة الكاملة

```bash
python scripts/e2e/cycle.py
```

ستٌّ وأربعون خطوة من أول لحظة إلى آخرها — تصنع كياناتها وتحذفها. التفصيل في
[`scripts/e2e/README.md`](scripts/e2e/README.md).

> في وضع التطوير رمز OTP يُطبع في **طرفية الخادم** (سطر `DEV OTP`).
> لتفعيل واتساب الحقيقي: `OTP_PROVIDER=whatsapp` ثم امسح QR من صفحة "بوت واتساب" في اللوحة.
