برنامج مزامنة رحّال غو مع برنامج الأمين
==========================================

شو بيعمل؟
بيقرأ أسعار المواد وكمياتها من برنامج الأمين، وبيبعتها لتطبيق رحّال غو لحاله كل ربع ساعة.
المادة اللي كميتها صفر بتصير «غير متوفر» بالتطبيق، وبترجع «متوفر» لما ترجع كميتها.
البرنامج بيقرأ بس — ما بيغيّر ولا شي ببرنامج الأمين.


التنصيب (مرة وحدة)
--------------------
1. حط هالمجلد كله على كمبيوتر الأمين، مثلاً: C:\RahalGo\Sync
2. من لوحة المتجر برحّال غو: الأصناف ← مزامنة الأسعار من الأمين ← «اعمل رمز مزامنة». انسخ الرمز.
3. انسخ ملف config.example.json وسمّيه config.json، وافتحه بالمفكرة (Notepad):
   - token: حط الرمز اللي نسخته.
   - mode: اختار وحدة من التنتين:
       "sql"     ← البرنامج بيقرأ من قاعدة بيانات الأمين مباشرة (الأفضل).
       "folder"  ← المحاسب بيصدّر ملف Excel من الأمين لمجلد، والبرنامج بيرفعه لحاله.
4. شغّل test.bat — بيقلّك شو رح يتغيّر بلا ما يغيّر شي.
5. إذا النتيجة صح، شغّل install.bat — وخلص. البرنامج بيشتغل لحاله كل ما يقلع الكمبيوتر.


طريقة sql (قراءة مباشرة)
-------------------------
- connection: عنوان قاعدة بيانات الأمين. مثال لما يكون SQL Server على نفس الكمبيوتر:
    sqlserver://localhost/SQLEXPRESS?database=اسم_قاعدة_الأمين&trusted_connection=yes
  أو باسم مستخدم وكلمة سر (حساب قراءة بس):
    sqlserver://اسم_المستخدم:كلمة_السر@localhost/SQLEXPRESS?database=اسم_قاعدة_الأمين
- query: جملة القراءة. لازم ترجّع أعمدة بهالأسماء:
    code (رقم المادة) · price (سعر البيع) · qty (الكمية) · name (الاسم) · barcode (الباركود)
  مثال (أسماء الجداول والأعمدة بتختلف حسب نسخة الأمين — منحددها وقت الزيارة):
    SELECT Code AS code, Name AS name, BarCode AS barcode, Price AS price, Qty AS qty FROM ...
- لتعرف أسماء الجداول: شغّل tables.bat — بيكتبها بملف tables.txt.
- currency: "SYP" إذا الأسعار بالليرة، أو "USD" إذا بالدولار.


طريقة folder (مجلد)
--------------------
- path: المجلد اللي بيصدّر إليه المحاسب ملف «قائمة المواد» من الأمين.
- pattern: نوع الملف، مثلاً "*.xlsx".
- قبلها لازم ترفع الملف مرة وحدة من لوحة المتجر وتحدد الأعمدة — البرنامج بيستعمل نفس الاختيار.
- البرنامج بيرفع أحدث ملف بالمجلد، ومرة وحدة لكل نسخة من الملف.


بعد التنصيب
------------
- بلوحة المتجر بتشوف: «البرنامج شغّال — آخر اتصال …».
- زر «مزامنة الآن» بلوحة المتجر بيخلّي البرنامج يزامن خلال دقيقة.
- كل شي بينكتب بملف sync.log جنب البرنامج.
- لإيقاف البرنامج: شغّل uninstall.bat.
- إذا عملت رمز جديد من اللوحة، الرمز القديم بيوقف — حط الجديد بـ config.json.
