# بيئةُ التجهيز — دليلُ التشغيل

> **`P-0`.** كلُّ ما في هذا المجلَّد يخدم غرضاً واحداً: **أن نستطيع أن
> نكسر أشياءَ بلا أن نمسّ إنساناً حقيقيّاً.**

---

# ١ · قرارُ المالك وما وقع فعلاً

**`TQ-4` قال: خادمٌ ثانٍ مخصَّص.** **ثمّ اختار المالكُ ٢٠٢٦-٠٩-٠٦ أن
تُشغَّل بجانب الإنتاج على `CX33` نفسِه** — وهو قرارُه.

**وذاكرةُ المشروع تقول إنّ `CX33` لم يُنشَر عليه شيءٌ بعد** (اشتُري
٢٠٢٦-٠٨-١٢ والرفعُ مؤجَّل). **فـ«بجانب الإنتاج» اليومَ يعني «على خادمٍ
فارغ»** — **وذلك أأمنُ ممّا يبدو.**

⚠️ **ويتبدّل الحالُ يومَ يُنشَر الإنتاج.** **وحينها**: تجربةُ استعادةٍ
أو إسقاطُ ذاكرةٍ على المضيف نفسِه **تنافس الإنتاجَ على القرص والذاكرة
والمعالج**، **ولا يحمي العزلُ المنطقيُّ من ازدحامٍ ماديّ.**

**والعزلُ المنطقيُّ مُثبَتٌ ومقيس** (انظر §٣).

**والاستثناءُ مسجَّلٌ بتاريخه وشرطِ إعادةِ تقييمه** —
[`TQ-4-EXCEPTION.md`](TQ-4-EXCEPTION.md). **ولا يُترَك يشيخ صامتاً.**

# ٢ · مواصفاتُ الخادم — **مقيسةٌ لا مقدَّرة**

**قِيست الحاوياتُ وهي تعمل** (٢٠٢٦-٠٩-٠٦):

```
rahalgo-staging-postgres   121 م.ب
rahalgo-staging-redis        3 م.ب
```

**والمحرّكُ والويبُ والبوّابةُ تُضاف إليها.** **والحدُّ الأدنى:**

| البند | التجهيزُ وحدَه | التجهيزُ بجانب الإنتاج |
|---|---|---|
| **CPU** | نواتان | **٤ أنوية** — `CX33` يفي |
| **RAM** | ٢ غ.ب | **٨ غ.ب** — `CX33` يفي |
| **DISK** | ٢٠ غ.ب | **٨٠ غ.ب** — `CX33` يفي، ⚠️ والنسخُ تأكل منه |
| **OS** | `Ubuntu 24.04 LTS` | نفسُه |
| **DOCKER** | `28+` مع `compose v2` | نفسُه |

**والمنافذ:**

```
٨٠٨٠  بوّابةُ التجهيز — HTTP
٨٤٤٣  بوّابةُ التجهيز — HTTPS (بعد النطاق)
٥٥٣٤  قاعدةُ التجهيز  ⚠️ **تُقيَّد بجدارٍ ناريّ**
٦٥٨٠  ذاكرةُ التجهيز  ⚠️ **تُقيَّد بجدارٍ ناريّ**
```

⚠️ **و٥٥٣٤ و٦٥٨٠ منشورتان للتجارب الهدّامة** (إسقاطُ الذاكرة · تدريبُ
الاستعادة). **ومنفذُ قاعدةٍ مكشوفٌ للإنترنت يُمسح خلال ساعات** — **فلا
يُفتحان إلّا لعنوان المشغّل:**

```bash
ufw allow 8080/tcp
ufw allow from <عنوانُك> to any port 5534 proto tcp
ufw allow from <عنوانُك> to any port 6580 proto tcp
```

**و`DNS/TLS PENDING`**: **النطاقُ لم يُشترَ بعد** — **فيُخدَم على
`http://<IP>:8080` حتّى يُشترى.** **وبعده يُبدَّل `:80` في
`Caddyfile.staging` بـ`staging.rahalgo.com` فتتولّى Caddy الشهادة.**

# ٣ · العزلُ — **مقيسٌ لا موعود**

**اسمُ المكدّس `rahalgo-staging` لا `rahalgo`** — **والاسمُ يحكم
الأحجامَ والشبكاتِ والحاويات.** **وقِيس:**

```
rahalgo_pgdata              الإنتاج
rahalgo_redisdata           الإنتاج
rahalgo-staging_pgdata      التجهيز
rahalgo-staging_redisdata   التجهيز
rahalgo-staging_backups     التجهيز
rahalgo-staging_uploads     التجهيز
```

**ولا حجمَ مشترك، ولا شبكة، ولا قاعدة** (`rahalgo` مقابل
`rahalgo_staging`)، **ولا منفذ.**

# ٤ · الإقلاع

```bash
cd deploy/staging
cp .env.staging.example .env.staging
# ثمّ املأ الأسرارَ — ولا تنسخ سرّاً من الإنتاج:
openssl rand -base64 36     # لكلٍّ من الثلاثة

./deploy.sh
```

**و`deploy.sh` يرفض:**

- **شجرةَ عملٍ متّسخة** — ولا مرشَّحَ من شجرةٍ تتبدّل.
- **بيئةً لا يرضاها حارسُ الإنتاج** — خمسةُ حرّاسٍ مستقلّة.
- **بناءً بلا هويّة** — `SOURCE_COMMIT` و`BUILD_ID` مشترطتان في
  `compose`.
- **إقلاعاً لا يقول من هو** — يُسأل `/api/v1/public/identity` بعد
  الإقلاع، **ويُتحقَّق أنّ الالتزامَ الذي يعمل هو الذي بُني.**

# ٥ · الأوامرُ الهدّامة

**ولا واحدٌ منها يعمل قبل أن يرضى الحرّاسُ الخمسة:**

```bash
go run ./cmd/stagingctl guard      # يقول حكمَ كلّ حارس
go run ./cmd/stagingctl reset      # يمحو البياناتِ ويُبقي المخطَّط
go run ./cmd/stagingctl backup     # نسخة
go run ./cmd/stagingctl restore F  # استعادة
go run ./cmd/stagingctl verify     # يعدّ ويثبت سلامةَ المخطَّط
```

**ورموزُ الخروج**: `0` تمّ · `1` فشل · `2` خطأُ استعمال · **`3` رفضه
الحارس** — **وهو الفرقُ الذي يُقرأ في خطّ نشر.**

**و`STAGING_PG_CONTAINER` تجعل الأداةَ تنادي `pg_dump` داخلَ الحاوية**
— **فلا يلزم تثبيتُ عميل بوستغرس على المضيف.**

# ٦ · تدريبُ النسخ والاستعادة — **نُفِّذ ٢٠٢٦-٠٩-٠٦**

```
١ · حالٌ معلومة        ٧ مستخدمين · منطقتان
٢ · نسخة               196,480 بايت
٣ · محوٌ               reset ⇒ ٠ مستخدمين
٤ · استعادة            pg_restore --clean
٥ · تحقّق              ٧ مستخدمين · منطقتان · ٦١ جدولاً · ١٢٨ هجرة · PostGIS
```

**`BACKUP = PASS` · `RESTORE = PASS` · `INTEGRITY = PASS`.**

⚠️ **وهذا تدريبٌ على التجهيز** — **ولم يُجرَّب على الإنتاج ولا يجوز.**
**و`OPS2` تبقى قائمةً حتّى تُجرَّب استعادةُ الإنتاج على هدفٍ آمن.**

# ٧ · أندرويد

**النظامُ يدعم التبديلَ أصلاً** — ولا ميزةَ جديدة:

```bash
./gradlew :app-driver:assembleDebug \
  -Prahalgo.apiBaseUrl=http://<IP>:8080 \
  -Prahalgo.mapsBaseUrl=http://<IP>:8080
```

**وحارسُ `P-8` يُثبت أنّ الحزمةَ لا تشير إلى الإنتاج:**

```bash
./testkit/devicerun.sh safety
```

⚠️ **والإصدارُ (`release`) لا يقبل التجاوز** — **عنوانُه حرفيٌّ
للإنتاج**، وهو صحيح: **حزمةُ متجرٍ تشير إلى تجهيزٍ كارثة.** **فبناءُ
التجهيز `debug` وحدَه.**

# ٨ · المزوّدون الخارجيّون

```
FCM        صامت    — لا ملفَّ اعتمادٍ مركَّب
WhatsApp   صامت    — OTP_PROVIDER=dev يطبع الرمزَ في السجلّ
```

هذا بغفلة** (`TestStagingProvidersAreSilentByDefault`).

# ٩ · ما وجدناه ولم نُصلحه (البند ٥٢)

**`P-0` تُثبت البيئةَ والدليل — ولا تعالج.**

## `R16` — **تأكّد**

```
جلسةٌ أُبطلت + Redis قائمة  ⇒  401
جلسةٌ أُبطلت + Redis ساقطة  ⇒  200
```

**والسببُ في `identity/service.go:749`:**

```go
n, err := s.rdb.Exists(ctx, sessionRevokedKey(sid)).Result()
return err == nil && n > 0
```

**وخطأُ الذاكرة يُقرأ «غيرُ مُبطَلة» لا «لا أعرف»** — **ومن طُرد من
المنصّة يعود بانقطاع ذاكرةٍ لا يعلمه أحد.**

**ولم يكن يمكن إثباتُه قبل اليوم**: `miniredis` لا تُسقَط.

## `D13` — **أُعيد إنتاجُه**

```
GET /media/  بلا توكن  ⇒  200 وصفحةُ سردٍ كاملة
```

**والمجلَّدُ فارغٌ هنا لأنّها بيئةٌ جديدة** — **وعلى قرصٍ فيه ملفّاتٌ
يُسرَد كلُّ اسمٍ فيه**، وفيها إثباتُ تسليمٍ لطلباتِ أناسٍ آخرين.

## `OPS1` — **قائمة**

```
/healthz يفحص:   postgres · redis
ولا يفحص:        مخزنَ الوسائط · الدفع
ولا بابَ جهوزيّةٍ منفصلاً
```

**فالموجّهُ يرسل الحملَ إلى عُقدةٍ لم تجهز** — **وسقوطُ مخزن الوسائط
لا يظهر.**

## عطبان في بذّار التطوير — **دَينُ أدوات**

**كشفهما البذرُ على قاعدةٍ نظيفةٍ حقّاً** (وقواعدُ التطوير بُذرت قبل
هذين القيدين):

```
seed كاملاً    menu_items.platform_section_id لا يقبل الفراغ
seed -customer user_addresses.area لا يقبل الفراغ
```

**و`seed -staff` و`seed -drivers` يعملان** — **وهما ما تحتاجه بيئةٌ
تُدار من اللوحة كما يُدار الإنتاج.**

**ولا يُصلَحان هنا** — دَينٌ مسجَّلٌ لدورة الإصلاح.

# ١٠ · التراجع (البند ٣٨)

**تراجعُ التطبيق:** يُعاد النشرُ من التزامٍ سابقٍ بالمسار نفسِه —
**والهويّةُ تُثبت أيَّ التزامٍ يعمل.**

```bash
git checkout <التزامٌ سابق>
./deploy.sh
```

⚠️ **ولا تراجعَ للقاعدة**: **الهجراتُ أماميّةٌ فقط ولا نظيرَ لها**
(`migrate.Up` وحدَها). **ولا يُخترَع تراجعٌ هدّام** — **والطريقُ
الوحيدُ استعادةُ نسخةٍ سبقت الهجرة.**
