# حزمةُ أصوات الملاحة العربيّة — رحّال غو

**أداةٌ تولّد ملفّاتِ صوتٍ عربيّةً جاهزةً لتطبيق السائق** من ElevenLabs،
ثمّ تُدرج في `res/raw`. **ولا محرّكَ نطقٍ آليٍّ في الجهاز** — الصوتُ
مُسجَّلٌ مسبقاً، فلا يتبدّل بين هاتفٍ وهاتف.

---

## المفتاح — يُقرأ من البيئة ولا يُكتب في ملفّ

```powershell
$env:ELEVENLABS_API_KEY = "sk_…"
```

```bash
export ELEVENLABS_API_KEY="sk_…"
```

**ولا يُكتب داخل المستودع ولا يُطبع في طرفيّةٍ ولا في تقرير.** و`.env`
مُستثنًى في `.gitignore`، والفهرسُ يُفحص عند كتابته فيسقط إن تسرّب.
**ومفتاحٌ مرَّ في محادثةٍ مفتاحٌ يُبدَّل.**

وإن غاب المتغيّر: **يعمل `dry-run` ولا يعمل ما سواه** — فلا يُصرف مالٌ
بالخطأ.

---

## الأوامر

| الأمر | ما يفعل | أيُصرف مال؟ |
|---|---|---|
| `npm run navvoice:dry-run` | يطبع الخطّةَ وعددَ الأحرف | **لا** |
| `npm run navvoice:voices` | يعرض أصواتَ الحساب ومعرّفاتِها | لا (نداءٌ مجّانيّ) |
| `npm run navvoice:qualify` | **خمس عشرة عيّنةَ اعتماد** | نعم — قليل |
| `npm run navvoice:generate` | الحزمةُ الكاملة | **نعم** |
| `npm test` | الاختبارات | لا |
| `npm run typecheck` | فحصُ الأنواع | لا |

**والترتيبُ مُلزَم**: `dry-run` ← `voices` ← `qualify` ← **استماعُ المالك**
← `generate`.

**ولا تُولَّد الحزمةُ الكاملةُ قبل أن يقول المالكُ حرفيّاً: «اعتمد
الصوت».** (بندُه ٢٥.)

---

## الصوت

يُبحث عن صوتٍ اسمُه **`rahalgo2`** في الحساب. وإن لم يوجد — أو وُجد أكثرُ
من واحد — **تتوقّف الأداةُ وتعرض القائمةَ ولا تختار**. أو يُثبَّت مباشرةً:

```bash
export ELEVENLABS_VOICE_ID="…"
```

**وصوتٌ خطأٌ يعني الحزمةَ كلَّها تُعاد** — وثمنُها مرّتان.

---

## ما يُولَّد

```
output/
  audio/          الملفّات بأسمائها
  android_raw/    نسخةٌ مسطّحةٌ لـres/raw
  qualification/  عيّناتُ الاعتماد
  manifest.json   الفهرس — يُقرأ في التطبيق
  manifest.csv    جدولٌ للمراجعة البشريّة (بعلامة BOM لأجل إكسل)
  state.json      البصماتُ — بها يُعرف ما يُتخطّى
```

**والفهرسُ يربط مناورةَ OSRM بملفّ صوت** — `maneuverType` و
`maneuverModifier` و`distanceMeters` و`roundaboutExit`.

---

## الذاكرة — لا يُدفع ثمنُ ملفٍّ مرّتين

**لكلّ تعليمةٍ بصمةٌ** من: النصّ المنطوق · معرّفِ الصوت · النموذج ·
الصيغة · إعدادِ الصوت. **فإن لم يتبدّل شيءٌ، تُتخطّى.**

**وتبديلُ إعدادٍ واحدٍ يُعيد الحزمةَ كلَّها** — لأنّ صوتاً بإعدادين في
حزمةٍ واحدةٍ يُسمَع نشازاً. و`--force` يُعيد كلَّ شيءٍ صراحةً.

---

## النصوص

**مصدرُ الحقيقة `src/corpus.ts`.** ولكلّ تعليمةٍ نصّان:

- **`ttsText`** — مُشكَّلٌ، ويُرسَل إلى المحرّك. **ولا رقمَ رقميّاً فيه
  أبداً** — «ثَلاثمِئَة مِتْر» لا «٣٠٠م»، **لأنّ المحرّك يقرأ الرقمَ
  بالإنكليزيّة أو يُهمله.**
- **`displayText`** — بلا تشكيل، لشاشة السائق.

وحارسٌ في الاختبارات يسقط إن دخل رقمٌ في منطوقٍ أو تشكيلٌ في مرئيّ.

### تصحيحُ نطقٍ خاطئ

`data/pronunciation-overrides.json` — قائمةٌ من `{from, to, why}`:

```json
[
  { "from": "الدَّوّار", "to": "الدَّوَّار", "why": "خرجت مُسكَّنةً" }
]
```

**والأطولُ يُطبَّق أوّلاً**، والتصحيحُ يبدّل البصمةَ **فيُعاد الملفُّ
المتأثّرُ وحدَه.**

---

## التحقّق — ولا يُعدّ ناجحاً بلا فحص

**نجاحُ النداء وحدَه ليس نجاحاً.** كلُّ ملفٍّ يُفحص قبل أن يُحفظ: رأسُ
`ID3` أو إطارُ MPEG، وحجمٌ فوق ١٠٢٤ بايت. **وردُّ خطأٍ بصيغة JSON يُحفظ
باسم `.mp3` يمرّ من كلّ فحصٍ يسأل «أموجودٌ الملفّ؟»** — ولا يمرّ من هذا.

وفشلُ التحقّق يُعاد كما يُعاد خطأُ شبكة. و٤٢٩ و٥xx تُعاد بتباعدٍ أُسّيّ؛
**و٤٠١ و٤٠٢ لا تُعادان** — فإعادةُ محاولةٍ على مفتاحٍ ناقصِ الصلاحيّة
تنتظر دقائقَ ثمّ تسقط كما سقطت.
